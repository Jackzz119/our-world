# Our World UI 交互体系基准

> 与 PROJECT.md（PRD）、TODO.md（任务）、STYLE.md（视觉风格）并列的第四份基准：**交互行为规范**。
> 依据：2026-08-10 cozy 游戏 UI/UX 七维度调研（案例：Spirit City / Sky 光遇 / 动森 / 动物餐厅 / Coffee Talk / Cozy Grove / VC2 / Bongo Cat / Palia 等，全文见调研记录）+ codex 三版比稿（`ai/concept/ui-system/`）。
> 状态：**提案待用户拍板**（2026-08-10）。拍板后按 §10 分期落地。

## 1. 总架构裁决：三档密度一套体系

调研铁证：**cozy 品类没有任何代表作使用 Discord 式常驻左 sidebar**；品类标配是「三层可见度」（L0 常驻锚点 / L1 可召回入口 / L2 全隐藏）。codex 比稿推 C（工程稳、肌肉记忆）、调研推 B（品类最贴合）——裁决取两者合体：

```
默认态（= mockup B）   底部悬浮玻璃胶囊条：房间切换 ｜ 聊天(未读点) ｜ 音乐播放态 ｜ 氛围(灯光/天气) ｜ ···更多
                      空闲 45s 自动淡出至 12% 透明度，鼠标动即回（放置产品的呼吸感）
沉浸态（= mockup A）   一键「眼睛」切换：胶囊全隐，只剩场景 + 物件 hover + 头顶气泡
                      （Spirit City 眼睛图标心智，品类标配而非加分项）
物件通道（恒在）       场景物件与角色是永远的功能入口，两档下都有效
```

C 版不作为常驻形态，但吸收两点：①「更多」popover 的功能分组逻辑归入胶囊 ②胶囊淡出后屏幕边缘留一个小把手（rail 可召回思想）。**Discord sidebar 正式退役。**

## 2. 功能入口地图（双通道，同一面板单一实现）

| 功能 | 场景物件通道（情感） | 胶囊/UI 通道（效率） | 打开形态 |
|---|---|---|---|
| 聊天 | **点对方角色**；新消息=对方头顶气泡 | 胶囊聊天钮（未读点） | 窄聊天 dock（非居中大窗），从触发处冒泡出现 |
| 时间线日记 | 书桌/日记本 | 更多 popover | 白纸卡（STYLE §8 规范） |
| 照片墙 | 墙面相框组 | 更多 popover | 白纸卡 |
| 时钟·闹钟 | 挂钟 | 更多 popover | 小卡 |
| 日历·纪念日 | 挂历（远期物件）/暂更多 | 更多 popover | 小卡 |
| 共享音乐 | 唱片机 | 胶囊音乐段（常驻播放态+曲名） | 悬浮播放器展开 |
| 心愿单 | 星光许愿罐 | 更多 popover | 白纸卡 |
| 灯光/天气 | 台灯（点=切灯光,远期） | 胶囊氛围段 | 双排 icon popover |
| 设置/装扮/商店 | 无（低频不占物件） | 更多 popover | 弹窗 |
| 模块控制器 | 无 | 更多 popover 内 grid | 开关小组件（**布局固定，无拖拽**——cozy 替用户做好 layout，HUD 拖拽编辑退役） |

原则：首次引导走物件（建立「功能住在房间里」心智）；高频（聊天/音乐）保证胶囊一步直达；低频只留物件+更多兜底。

## 3. 房间切换（三房间：书房 / 棋牌室 / 植物园）

- **主通道**：胶囊左段三枚**房间缩略圆片**（不是文字列表）；辅以屏幕左右边缘 hover 才实心化的柔和箭头（mockup A 的箭头并入）
- **切换动效**：**水平平移** 320–400ms ease-in-out + 背景层 20% 视差——房间在心智上物理相邻（猫咪后院/动物餐厅原型）；淡入淡出只用于时辰/模式变化，不用于空间移动
- 排列固定：书房 ⇄ 棋牌室 ⇄ 植物园，箭头方向与排列一致
- 键盘 1/2/3 直切；触屏横滑手势
- **presence 彩蛋**：对方所在房间的缩略片上挂她的小头像点——「她在植物园」本身就是陪伴信息
- 房间内门/拱廊热点（远期美术）点击=同样触发平移，纯世界观服务

## 4. 聊天体系

- **世界内**：消息以对方角色头顶短气泡呈现（一次果冻 wobble，动森原型）；表情/贴纸=角色直接播动作（Sky emote 原型，接现有贴纸系统）
- **UI 层**：窄聊天 dock（历史+输入），可一键折叠；**绝不做居中覆盖大窗**；聊天文字区垫半实底（玻璃上排小字是 Palia 实证过的可读性坑）
- **长椅仪式（招牌场景，Sky 聊天长椅原型）**：双方都在线且空闲时，两只小狗同坐沙发 → 进入「对话模式」——聊天 dock 轻轻升起、环境音渐弱、灯光向沙发聚拢。雨天+长椅+共听音乐=产品名场面（落地排 MVP 后，先做气泡+dock）

## 5. 物件 affordance 三级（解决「找不到能点的东西」）

1. **静默态**：无任何标记（场景是插画）
2. **hover/focus**：水彩晕染柔光 + 物件微动（呼吸/轻晃，出货箱开盖原型）+ 光标变化
3. **有新内容**：物件头顶冒**小光点/小气泡**（badge 的 diegetic 形态——红点宁可做成柔光）

兜底（Cozy Grove 反例的解药）：**长按/双击场景空白处 → 全部热点亮轮廓 2s**；首次进入只对书桌做一次 1.5s 低频提示，之后永不主动闪。触屏无 hover → 点按即二级态。

## 6. 动效参数表（全站 ≤5 种，同类动作永远同参数）

| 动作 | 参数 |
|---|---|
| 面板/卡片开合 | 220ms ease-out，从触发物件位置 scale 0.9→1.02→1 冒泡 + 轻微上浮 |
| 房间平移 | 320–400ms ease-in-out + 20% 视差 |
| 按钮 hover | 120ms 浮起（translateY -2px + 阴影加深） |
| 按钮点击 | spring 下压回弹（scale 0.96 → 回弹，超调 ≤4%） |
| 聊天气泡出现 | 头顶 scale+上浮 + 一次轻 wobble |

红线：转场不超 500ms；纯淡入=工具软件感、硬滑入=营销弹窗感，都不用。

## 7. 音效体系：水滴系（与雨 ASMR 同一材质宇宙）

- **水滴 = 确认**、**涟漪 = 切换/翻页**、**湿润 soft pop = 点击**（300–600Hz 圆润起音、无锐利 attack、极少混响）
- 动森法则：音效时值与动效时值对齐（150–250ms）；同一动作永远同一声音；连续点击做音高阶梯（+2 半音递进）
- 全局音效音量随 ASMR 音景独立可调、可全关
- 候选资源：BOOM CASUAL UI（商业）、shmyak ui paper（纸质，贴水彩）、Kenney Interface Sounds（CC0 起步）

## 8. 质感公式（多场景兼容的答案）

**玻璃为骨、纸为肉、木为饰、果冻为反馈**：
- 玻璃拟态 = 面板底材（唯一在书房/棋牌室/植物园都不违和的透明底材——借背景成色，房间换了 UI 自动换气质）；磨砂加重 + 细描边 + 文字区半实底
- 纸 = 内容卡（日记/照片/心愿单）
- 木 = 房间专属边饰（随场景微调，制造房间性格）
- 果冻 = 按钮/气泡/微交互（大面积会腻）
- 圆角 16–24px、pastel 大耳狗色调、手写感标题字（中文选型待定）+ 圆润正文

## 9. 反模式红线（调研 12 条全文见调研记录，此处为执行摘要）

多层菜单/重复流程 ❌｜可点物与装饰无法区分 ❌｜图标含义靠猜 ❌｜按钮少但步骤多 ❌｜玻璃底排小字 ❌｜UI 藏不干净（隐藏后残留）❌｜重要功能藏进深层 ❌｜一次平铺全部信息 ❌｜红点/成就压迫感 ❌｜设置项过多诱发把玩 ❌｜动效通胀 ❌｜hover-only 无触屏后备 ❌
