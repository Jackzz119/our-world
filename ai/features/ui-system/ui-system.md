## 1. 目标与范围

视觉签名是**映着小屋暖光的细纹磨砂玻璃**。场景给氛围，UI 提供稳定阅读和清楚操作。A/B 共用颜色语义、文字、控件与状态；C 保持物件自身材质。

| 体系          | 现役范围                                                                      | 本地实现                                                                                                      |
| ------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| A 场景悬浮 UI | 导航、天气、聊天窄卡、音乐两态、纪念卡、头顶标签与气泡                        | 导航为母材质，其他浮窗已接共享外壳；密集内容用稳定阅读底                                                      |
| B 任务界面    | 设置、日历/提醒、完整聊天、选择器、好友/DM、照片/原图、心愿；世界设置保留实现 | 连续磨砂外壳 + 圆角不透明内衬，随时辰改变暖冷；原生任务弹层                                                   |
| 边缘页面      | 登录、重置、大厅、加载/错误                                                   | 真实书房素材 + 同源外壳、内衬、控件与状态                                                                     |
| 内容页：回忆  | 日记（手帐 / 日历 / 书本）+ 照片墙（拍立得 / 软木板 / 相册 / 放映）+ 共用灯箱 | 2026-10-01：用户定下产品分层，日记和照片墙是内容页——桌面正中、手机全屏（`ui/content-page.tsx`），样子随时切换 |

**入口不决定材质**：唱片机打开 A 音乐浮窗，挂钟打开 B 提醒，桌上的书和照片打开回忆页（内容页，2026-10-01），心愿沿用 B 通用壳。世界设置的外壳随 B 统一，用户 2026-09-19 暂不恢复入口的决定继续有效。

**日记冻结已解除**（2026-09-30 用户要求日记与照片墙统一迭代，旧日记先不删）：默认日记是回忆面板（`surfaces/memory-surface.tsx`），棕皮书的正文、编辑、详情、翻页、素材、遮罩与纸张规则原样留在 `journal/`，设置里选「书本（旧版）」时使用。场景底图、角色美术与活物光照引擎未随换肤重做。

## 2. 母材质与环境机制

导航保持 [原导航实现](../navigation-glass.md)。纹理是固定的 `public/ui/nav/frost.webp`，不是运行时随机噪声；透景来自背景模糊，薄边来自 CSS 渐变，不是真实场景反射。

`WorldPage` 的 `.app.ui-environment` 持有环境变量。`useUiEnvironment` 在时辰或场景挂载变化时读取导航配色，供 A/B 使用；不逐帧采样画面。未进入房间的页面使用环境预设，登录/重置采用暮色。

内衬不透明：黄昏暖灰褐、暮色灰紫、夜晚深暖灰。纹理与材质公共值只在 [ui-system.css](../../../src/themes/cinnaglass/ui/ui-system.css) 维护，不在文档另抄一套 token 表。场景灯光、光向、天气与 UI 的完整共同光环境仍是后续独立设计；不再把它作为本轮 UI 迁移的前置条件。

## 3. 公共基础与兼容

- `ui/ui-system.css`：`.ui-environment`、`.ui-surface`、`.ui-liner`、按钮、图标按钮、字段及 TaskDialog 布局；米白文字、暖金操作、错误/成功语义。
- `ui/task-dialog.tsx`：原生 `showModal()`、标题关联、初始焦点、背景隔离、关闭与焦点归还；卸载式聊天弹窗也覆盖关闭清理。
- `ui/use-ui-environment.ts`：导航配色读取与紧凑视口判定；功能样式只定义布局和领域细节。
- 新设置用「减少透明效果」提供稳定底色，替代旧卡片配色选项。`ow-tweaks-v1` 中旧 `glassStyle` 保留兼容，不重写 C 的存储或材质。
- 旧 `--cg-*` 与无消费者的玻璃原子样式已清理；`--shell-* / --glass-* / --craft-*` 中仍被 C 或兼容组件使用的部分保留。聊天局部映射覆盖旧纸张子级声明，避免深底深字。
- 原有 UI 动效不作为新规范。用户已选定环境 A 双圆收纳，局部透镜滑动/展开接入，参数与截图见当前主题。2026-09-29 全局动效体系按用户要求本地实现：token 在 `ui/motion.css`，低动效模式由 `ui/motion-preference.ts` 发布到 `html[data-motion]`，手机托盘 `ui/sheet.tsx`；没有引入动画库（调研与取舍见 [ui-motion](../../design_system/codex-visual/ui-motion/ui-motion.md)）。

## 4. 交互与真实能力

### 4.1 浮窗与弹层

A 不使用全屏遮罩；桌面按停靠区布局，窄/矮屏聊天与音乐展开互斥，底导航保留操作空间。音乐显隐、展开和播放独立；恢复播放器不创建第二个音频状态源。

B 打开后背景不可点或 Tab，标题与关闭入口保留，正文滚动。聊天附属选择器受任务窗约束，Esc 先收起选择器并回触发按钮；原图属于嵌套任务窗。隐藏内容不可获焦。日记现有显隐/草稿规则保持原状。

### 4.2 状态与数据边界

- **设置**：昵称真实写库，失败留稿；邮箱只读；改密先验证当前密码；退出失败可重试。没有虚构的统一「应用」按钮。
- **音乐**：`useMusicPlayback` 驱动本机 WebAudio 和弦音景（8 首），进度来自音频时钟；不是外部歌曲文件或双人同步播放。暂停/静音/换曲/拖动/模式显示与真实状态一致；隐藏控件不中断播放，离开房间释放音频。主页面的歌词随音频时钟高亮、点句跳转，点歌单行即播；收藏只存在本机（`ow-music-v1`）。
- **天气**：左上双圆入口、互斥开关、点击/拖动/键盘选择，由 `Ambience` 触发现有 `WorldPage → useWeather` 与偏好存储；天气状态压缩为短词，未知温度不显示数值，失败后可选晴/雨。旧云/雪值保留真实名称且不误选实况；雪景未实现不得表示已实现。较矮桌面展开向右避让导航。
- **日历/提醒/心愿**：保留本机列表能力并明确不等于云端同步或到时通知；纪念日缺失显示未设置，不回退假日期。世界设置入口仍暂缓。
- **聊天**：保留真实消息、贴纸、反应、历史、失败重试、编辑/删除和好友/DM。好友导航折叠为次级入口；导入与好友操作有错误反馈、IME 闸门和内联删除确认，不用新样式掩盖数据能力。
- **在场状态**：未接 Realtime Presence，不展示假在线绿点或把占位文案当真实状态。

## 7. 验收与剩余范围

浏览器基线覆盖三时辰、桌面/窄屏、真实组件材料与可读性、显隐/恢复、键盘进入/退出/焦点、嵌套选择器、空态/错误/重试、长内容，以及本机音乐行为。账户/好友/导入等写操作通过隔离替身验证，不把模拟结果称为真实双人后端联调；普通测试过程留会话，不逐轮落盘。

仍待专项：iOS/Safari 与 Android 真机软键盘、系统 125%/150% 缩放及 200% 文本、屏幕阅读器/高对比度、低端设备 GPU/内存/长驻模糊成本、双端网络与真实共享数据联调。新房间上线时补实景验收，缩略图不能替代完整场景。

维护要求：TypeScript 与 Vite 构建、变更文件静态检查和设计链接保持通过；正文与关键控件在实际合成背景中验收，不只看 token 色差。旧棕皮书内部不属于这轮验收。

## 8. 当前决定

A/B 与边缘页面已按用户授权接入统一设计，最新视觉展示见 [主题规范](../../design_system/uiux/cinnaglass/ui-system.md) 与 [全局预览](../../design_system/preview.html#ui)。用户批准方向和代码已实现是不同事实；尚未执行的真机/性能检查继续列在 TODO，不重新写成「其余界面待迁移」。世界设置入口暂缓持续有效；C 冻结与「M6 后置」已分别于 2026-09-30、09-29 解除。
