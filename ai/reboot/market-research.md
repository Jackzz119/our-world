# 市场调研：放置陪伴品类

> Reboot Kit 之一。两线调研：Steam 陪伴/放置/lofi 品类（§1-6）+ 中国/亚洲虚拟自习室（§7）。
> 数据查证日 2026-08-09（Steam 商店页 + appreviews API 直接抓取；其余标注来源）。粗估销量 = 评价数 ×30~50，该品类实际倍率可能更高（Rusty's 官方销量/评价数 ≈ ×77）。

## 1. 品类地图：三种形态

| 形态 | 定义 | 代表 |
|---|---|---|
| **A. 全屏/窗口氛围工具** | 打开当「学习背景」，自带计时器/待办，本质是番茄钟的游戏化外壳 | Spirit City、Virtual Cottage、Chill Corner |
| **B. 桌面覆盖层放置（second-screen idle）** | 透明背景贴屏幕边缘，挂机产出，与工作共存 | Rusty's Retirement、Tiny Pasture、Ropuka |
| **C. 桌宠 / mascot** | 角色直接活在桌面上，对用户输入即时反应 | Desktop Mate、Bongo Cat |

**我们的产品 = A 的场景 + C 的角色反应 + 双人私密——这个组合市场上没有人做。**

## 3. 关键案例深读

### Spirit City: Lofi Sessions —— 品类天花板

3 人团队、$11.99、97% 好评、首周 5.5 万份（开发者自述）。循环 = 任务/习惯计时 → XP/货币 → 装扮房间收集精灵。UE5 实时渲染。**赞**：ADHD/焦虑人群专注辅助、可混音音景、低资源占用。**弹（照单避坑）**：精灵是「带眼睛的家具」缺互动深度；音景组合**不记忆上次设置**；笔记功能比不上记事本。评论区有人明确请求「和朋友一起挂机自习」——需求在，官方没做。

### Virtual Cottage → Virtual Cottage 2 —— 方向验证者

初代免费 97% 好评，**官方特性就有「窗外光照与系统本地时间同步」**——我们时辰系统的六年先例。二代 2026-03 上线（$7.99，96%），**加入好友同屋自习 + 公共咖啡馆，通信刻意压到极简聊天+表情**。品类头部已验证「共享空间一起专注」是下一步，但做的是好友/陌生人房，**没有亲密关系向、没有共享记忆数据**。

### Rusty's Retirement —— second-screen idle 定义者

1 人开发、$6.99、官方销量 55 万+。屏幕底部透明农场条，「你工作，它干活」。其成功引发 Steam 官方 2025 放置游戏节。**最大差评是 CPU 占用 6-16%**——对「挂一整天」的软件是致命抱怨。

### Desktop Mate —— 流量巨大口碑翻车的反面教材

200 万下载但 60% 好评。角色在场感全品类最强（骨骼物理/视线追随/摸头/休息提醒），**好评区最动人的是「KAITO 提醒我睡觉」式主动关怀**。翻车原因照单全收：每角色 $14.99 被骂掠夺性定价、封杀自定义模型催生开源竞品、ToS 声明可随时收回内容、GPU 占用高。

### Bongo Cat —— 「把你的劳动实时可视化」

免费、28,431 评 96%、峰值 17 万在线，但**月收入仅 ~$3,000**（流量≠收入）。核心魔法：你每敲一次键盘猫拍一下鼓。2025-08 上线 meowtiplayer：好友的猫摆上你桌面、他们敲键盘他们的猫实时拍——**「好友远程在场感」的最轻量实现**。警示：被传「键盘记录器」的信任恐慌——对我们这种私密应用，数据隐私要当宣传级卖点做。

### CottageVille —— 与我们概念最像的失败样本（必读）

2023-11、$6.99、**Steam 只有 1 条评价**，itch 免费送。功能清单几乎就是我们的产品：装扮小屋、控制天气时间、好友活动状态、互访小屋、白板待办、lofi 播放器、**物件里藏小游戏和惊喜**。死因解剖：
1. **无角色**——空房子没有「谁」在陪你
2. **无挂机产出**——没有回访理由
3. **好友社交冷启动死循环**——没人玩=没好友可邀
4. 零营销

**我们对四条死因的天然解**：①两只角色是画面主角 ②内容由两人真实生活持续产生（照片/消息/纪念日），场景只是容器 ③用户成对进入，天然免疫冷启动 ④自用产品不需要营销。概念对≠成功，差的是执行结构——这个样本值得贴在墙上。

## 4. 双人/情侣向空缺：确认存在

- **Steam 端没有「两个人共享一个陪伴空间」的成功产品**：9/10 成功案例纯单机；最接近的三个都不是情侣向（VC2 好友自习房无共享数据、Bongo Cat 联机无空间概念、CottageVille 已死）
- 众筹中的 Loftia 明确打「异地情侣一起装扮家、一起自习」宣传（Kickstarter 成功、未发售）——需求已被从业者盯上，没人交付
- **移动端情侣 App**（Couple2、Cozy Couples、CozyCove：共享虚拟家/宠物/签到/纪念日）证明付费需求真实，但全是功能清单式 App，**没有一个做出「常驻场景+角色在场+氛围陪伴」的产品体验**
- **结论：「桌面/网页级双人常驻陪伴场景 + 真实共享数据（时间线/相册/聊天）」这个交叉点是空的。单机陪伴游戏证明了形态，情侣 App 证明了需求，没人把两者接起来。我们已有的 timeline/相册/聊天恰好是所有竞品最缺的「真实数据层」。**

## 5. 成功要素与商业模式规律

### 成功要素（按重要性排序）

1. **与「正事」共存而不是抢时间**——打扰成本越低越成功（覆盖层>窗口>全屏），决定性能预算/视觉噪音/通知策略的一切取舍
2. **一眼可读的可爱 + 一句话概念**（「猫拍你的键盘」）——缩略图级传播力
3. **真实效用做留存锚点**（计时器/待办/习惯）——每天打开的理由不依赖内容更新
4. **挂机产出制造回访钩子**——离线也在发生的事
5. **收集与装扮做长线**——低压力收集是唯一被接受的进度系统，肝度一高立刻挨骂
6. **低价或免费**；7. **快速响应社区愿望单**；8. **直播安全的音乐**

### 定价规律（若远期商业化）

- 口碑最安全：买断 $3.99–11.99 + 支持者包（打赏性质）+ 内容 DLC $2.99–7.99
- Desktop Mate 教训：高价角色 DLC = 掠夺性定价骂名
- **通用红线：核心陪伴体验（看到对方）绝不能进收费墙**，收费只能落在装扮/音乐/打赏

## 6. 陪伴感设计手法清单（可直接套用）

- **角色微动作循环**：翻页、伸懒腰、打瞌睡、偶尔抬头看屏幕外——关键是**低频+随机**，不是循环 GIF
- **对用户真实行为的即时反应**（Bongo Cat 原理的双人版，我们的金矿）：**对方在输入聊天=角色执笔写字；对方在翻相册=角色拿起相框；对方开着页面=角色在书桌前；离线=角色盖毯子睡着**——比任何聊天气泡都更「陪伴」，且聊天/时间线数据已具备
- **摸头/点击反馈**：点击角色有专属反应
- **系统时间同步光照**：Virtual Cottage 六年验证；双人变体=异地时显示「对方那边的天色」，把时差做成情感点
- **音景分层 + 记住上次组合**（Spirit City 最大差评就是不记忆）
- **离线持续生长**：回来时场景有变化可看（墙上多张拍立得、窗台植物长高）——两人的每日轻仪式（签到/发帖）喂养场景
- **角色主动关怀**：「对方还没睡，提醒 TA」「TA 设了 25 分钟专注，陪 TA 安静一会」——Desktop Mate 好评区核心素材
- **功能藏物件 + 可发现性提示**（微光/悬停动效）——CottageVille 教训：藏得没人知道
- **最小陪伴视图**：second-screen 低打扰是品类最强共识；web 端可用 Document Picture-in-Picture 做小窗（角色+天色+对方状态）——把 Rusty's 的形态优势搬进浏览器

### 避坑清单

1. **性能是品类第一差评来源**（Rusty's CPU 6-16%、Bongo Cat 卡顿、Desktop Mate GPU）——「挂一整天」的软件 3% CPU 都会进差评：不可见暂停渲染、帧率上限、低功耗模式
2. **角色不能是「带眼睛的家具」**：随机微动作 + 对用户行为的反应 + 偶发主动行为，三层缺一不可
3. **别做肝度**——与陪伴人设自相矛盾
4. **信任红线**：私密数据归属与隐私当宣传级卖点做，不只是合规项
5. **内容天花板**：纯装扮收集会玩完；我们的解法天然存在——内容由两人真实生活持续产生
6. **一个人先来时也要有单人可玩的最小体验**（等待另一半上线的时段仍是完整产品）

## 7. 虚拟自习室调研（中国/亚洲线）

> 你记忆里那款「小人坐在自习室、别人都能看到」的产品就是 **CoStudy（一起自习）**——至今还活着（2026-08 刚发 7.6.0），华为渠道安装量约 467 万次（2021 数据）。

### 案例速览

| 产品 | 「让别人看到你」的方式 | 现状 | 关键教训 |
|---|---|---|---|
| **CoStudy** | 虚拟校园→选教室→选座位，卡通小人坐下，同教室互相可见；离开太久被踢出教室 | 活着，会员订阅 ¥168/年 | 形象+座位的在场感有效；但免费限次压核心动作伤口碑；被评「有趣大于实用」 |
| **Timing** | 真人状态流：视频打卡、连麦自习、图书馆场景；关注页像微博 | 曾达华为渠道 4899 万安装（品类天花板），近年声量大跌 | **9.0 短视频化引发老用户反弹被迫回调**——「点进去为了学习，刷 20 分钟动态书还没翻开」 |
| 番茄 ToDo 自习室 | 同室成员互相可见专注状态与时长；加入码私密房 | 活着（考研常青工具） | 房间制+加入码即可支撑双人私密房，无需形象 |
| **Forest** | 不做实时形象，做**结果性共同资产**：多人种树、一人退出全员树枯（连坐） | 活得最好（2020 年即 400 万付费用户，12 年长青） | **不做社区不做内容，把陪伴压缩进一个极简共同仪式，反而穿越周期** |
| 韩国 YPT | 纯数据实时性：组内实时可见「此刻是否在学、今天学了多久」 | 活跃（全球 500 万用户） | 不做场景拟真也能有在场感——「一排正在走的计时器」就是自习室 |
| 日本 Studyplus | 异步痕迹流：学习记录 SNS，互相点赞 | 900 万会员，日本受验生渗透率 62% | **异步痕迹比实时直播省力，留存反而更稳** |
| 小番茄（iOS） | 头像上下浮动 + 两档状态（专注中/酝酿中=在碰手机） | — | **极低成本实现「看得见的状态」——两档状态就够传神** |
| 专注崽崽 | 专注孵蛋养宠 + 室友间传「小纸条」（不打断的轻互动） | 活着 | 轻互动必须异步、可延迟消费 |
| 微信读书组队 | 利益驱动组队（抽无限卡） | 福利收紧后关系即散 | **纯利益绑定零情感留存** |

### presence 设计模式判定表（十种模式的有效性）

| 模式 | 判定 |
|---|---|
| 形象+座位（CoStudy） | **有效但有天花板**：场景应服务于状态传递，不是游戏本体 |
| 实时状态牌（小番茄/YPT） | **最有效、成本最低**：两三档状态（忙碌/休息/不在）比复杂动作表更传神 |
| 真人摄像头（Timing/study with me） | 对极核心考生有效，无法放置化，心理成本高 |
| 连坐共同体（Forest 多人树） | 有效，但失败会互相埋怨——**双人场景需去掉惩罚语义** |
| 结果性共同资产（森林/花园/宠物） | **有效且是留存关键**：把不可见的时间变成会生长的东西 |
| 排行榜/热力图 | 公共场景有效；**双人场景基本无用甚至有害** |
| 异步痕迹流（Studyplus） | **有效且最省力**：错峰的两人也能感知彼此努力 |
| 动态 feed 社区（Timing 9.0） | **被验证的歧路** |
| 利益组队（微信读书） | 拉新有效，陪伴感为零 |
| 轻互动不打断（小纸条） | **有效**：陪伴需要出口，但必须异步 |

### 双人/情侣场景 vs 公共自习室的需求差异（产品设计基石）

- **目的倒置**：公共室「学习是目的，别人是手段」；情侣「**陪伴是目的，各自忙碌只是场景**」——公共产品三板斧（排行/惩罚/陌生人氛围）在双人场景全部失效甚至有毒
- **监督 → 被想念**：公共室靠「被看着不敢摸鱼」；情侣要「我忙我的，但我知道你在、你也知道我在」
- **匿名 → 全透明**：情侣对彼此全透明（在忙什么、大概何时结束），且这份透明**只对彼此**
- **竞争 → 共同产物**：情侣需要「我们共同养成了什么」——正好接 timeline/相册：共处时段本身沉淀成记忆条目
- **失败语义**：失败若被设计成「让对方受损」，制造的是愧疚和争吵

### 最值得抄的 3 个机制

1. **一室两座 + 余温物**（CoStudy 座位制的双人化）：房间里两把椅子是「TA 的位置」；姿态映射真实状态（专注=伏案、后台=打盹、离开=座位空但留下杯子/外套这类「余温物」）。状态语义抄小番茄的极简两三档
2. **共同养成资产 × timeline 融合**（Forest 正反馈版）：两人各自忙碌的**重叠时段**自动养一株东西，长成后自动落进 timeline 成为共同记忆（「这周我们同室共处 6h12m，养出了第 3 朵花」）——只做正反馈生长，去掉枯死连坐
3. **小纸条 + 重逢时刻**：忙碌中给对方桌上放张纸条/一杯咖啡（对方结束专注才看到）；结束时两个小人碰头 + 今日共处时长小结——**presence 的高光不在过程中，而在「下课那一刻」**

### 最该避开的 3 个坑

1. **别做内容流/广场**（Timing 之鉴）：互动长在房间和物件上，不长在信息流里
2. **别做惩罚式监督**：不做「你没坚持所以我们都受损」，只做「你在的时候我们都变好」
3. **别让在场变成表演负担**——**零成本在场铁律**：只要 App 活着，形象就自然在那里；任何要「经营」的 presence 会让更忙的那个人先放弃，产品随之单边死亡

---

## 一句话总结

**品类胜负手 = 低打扰的在场感 + 真实效用 + 可爱的持续微反应。单机陪伴已卷成红海，好友自习刚起步（VC2，2026-03），而「两个人的私密陪伴空间」在 Steam 和 Web 端都是无人区——我们手里的时间线/相册/聊天正是所有竞品都没有的内容引擎。**
