## 别踩的坑
- 容器里 Playwright 的 `setInputFiles(路径)` 会悄悄丢掉中文文件名的文件：传 `{ name, mimeType, buffer }`（见 `scripts/check-music-library.mjs`）。
- 开着 `pnpm dev` 时改 `src/lib` 会让 Vite 整页刷新，正在跑的浏览器回归会报「Execution context was destroyed」——跑回归时别改源码。
- 测试页要 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` 有值才能启动：`VITE_SUPABASE_URL=https://example.supabase.co VITE_SUPABASE_ANON_KEY=x pnpm dev`。
- 开源 Chromium 没有 AAC 编码器也放不了 AAC：省流版的 AAC 路径要在 Mac / Windows 的 Chrome 或 Safari 26 上验。
- 测批注层的页面要带 `<meta name="viewport">`（发布时宿主会加）：直接打开只有正文的发布副本，手机视口会按 980px 排版。
