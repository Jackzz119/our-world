# Blender 公寓场景文档

> 最后同步：2026-04-17（五房间 + 后院版本，新增乐高玩具房）
> 场景用途：still-love Our World 主场景，导出 GLB 供 React Three Fiber 加载

---

## 场景概览

- **房间总数**：5 间（书房、卧室、猫猫房、客厅/厨房、乐高玩具房）+ 后院
- **整体范围**：X: -8 ~ +12，Y: -20 ~ +14，高 3.2m
- **坐标约定**：原点在书房地板中心；前墙朝 +Y，后墙朝 -Y，右方向 +X，左墙 -X

### 平面布局

```
              客厅/厨房 Y:+5~+14
              ───────────────────
  书房          │           │
X:-8~+4        书房 / 卧室  │ ← Y:-5~+5
               │           │
              ─────────────────── Y:-5
                            猫猫房（卧室后方）
                            X:+4~+12, Y:-5~-11
              ─────────────────── Y:-11
                  后院（梧桐树）
                  X:-8~+12, Y:-11~-20
```
