# EXTRA-STEPS — 拓展审核步骤

这里放五个通用审核步骤之外的额外要求。可以在运行技能前手动添加，运行中也可以补充。
第四步结束时核对并按文档顺序执行，全部拓展之后由第五步统一收尾。每个启用步骤默认覆盖整个项目，
同样要真实调研、拆分子步骤、沟通方案、审核并报告。

**当前没有启用的拓展步骤。** 下方是禁用示例，启用时将状态改为“启用”并删除这句无启用说明。

## X01 — 示例：素材体积与仓库生命周期专项

- 状态：禁用
- 目标：在第一步登记的重复素材与 400MB+ 二进制基础上，评估 Git LFS / 仓外归档 / 批次保留策略。
- 验收：逐目录列体积、消费者、保留价值与迁移方案；实际迁移须用户另行授权。

## 添加方式

复制上面的条目，使用新的 ID，填写状态、目标和验收条件。自然语言要求也可使用，
agent 会据实际项目拆成子步骤，并把进度与后续改进写入本目录 `STEPS.md`。
示例或禁用条目不算待执行任务；没有启用项时，完成第五步后交付结果并确认是否结束审核。
