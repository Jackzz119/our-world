## 2. 世界观与角色

- **画风**：水彩手绘、毛绒质感、pastel 暖光——大耳狗（Cinnamoroll）色调的**原创**演绎
- **双角色**：蓝耳小狗 = 男主、粉耳小狗 = 女主（沿用作者色体系：我=蓝 / 对方=粉）
- **原创性边界**（量产前必做人工 IP 相似性评审）：区别于三丽鸥官方形象的稳定特征——奶油/浅棕头顶斑块、彩色锥形垂耳、眉斑、围巾、毛绒四肢；不用纯白云朵轮廓
- 角色**不走动、不进场**：座位常驻，只切状态（在线=回归座位亮起，离线=空位留痕）

## 3. 场景规范：房间模板架构

**核心思想（2026-08-09 用户定）：房间 = 可量产的模板，角色 = 独立动画层，两者正交。**

一个房间模板包含：

```
房间模板 = 背景场景图（×4 时辰变体）
         + 两个座位锚点（角色贴装位置 + 遮挡关系）
         + 热点位（物件坐标 → 功能映射）
         + 窗户区（天气层贴装位）
         + 音景预设（该房间的默认 ASMR 组合）
```

- 角色动画与房间解耦 → **开发很多房间类别不增加角色成本**，回避 3D 全屋的体量问题
- MVP 只做 1 个房间（书房，概念图 01 构图）；模板结构从第一天就按可量产设计
- **场景媒介待专门讨论**（TODO R1 首条）。候选按噪点从低到高：①纯静态图 ②静态图 + 微动效层（光斑/蒸汽/雨，CSS/shader）③3 渲 2 分层（Blender 预渲染 base + 光照层运行时合成）④Live2D 式摇晃/呼吸变形。**噪点原则：放置产品，越安静越好**——宁可静止也不要持续晃动的「活」

## 4. 光照与时辰

- **时辰四档**：早晨 / 白天 / 黄昏 / 夜晚，跟随**用户系统时间**自动切换，600–900ms 交叉淡化
- **UI 外壳明度递进**（继承已定稿决策 D-12）：外壳随时辰 近白 → 雾灰 → 石墨；场景与 UI 读同一个 mood 源
- **实体纸与透明壳分开（2026-09-07 当前）**：B「苔绿手札」效果已被否决。日记改为批准稿的棕皮旧米纸，正文 #594126，以真实纹理与暖褐墨相融；纸不是恒白，也不要求亮过灯泡/天空。专属真源为 `journal-room.css` 与 `ui-system.html#journal-room-object`。照片/心愿/日历/设置仍沿用 `materials.css` 的旧暖灰纸 #D8CDBA、正文 #443E35，尚未重做，不能把它们登记为新稿已迁移。
- **导航当前材质**：中性微纹理透明玻璃，受真实 mood 的暖/冷反射，保留用户认可的局部反光与悬停/按压暖光。真源为 `shell/navigation-glass.css`；不是固定透明绿色，也不把书页改成玻璃。
- 夜档用室内暖灯（台灯/许愿罐）托住角色脸部，低亮度屏上蓝耳轮廓不可丢

## 5. 天气

- 与现实脱钩，手动切换：晴 / 雨 / 雪——是氛围开关不是天气预报
- 雨雪只出现在窗外层 + 屏幕级粒子，**不烘进场景底图**（避免循环接缝）
- 远期情感点：异地时可切「对方那边的天色」

## 6. 动画原则

- **低频 + 随机**：微动作循环（呼吸/眨眼/翻页）间隔随机化，拒绝等间隔循环 GIF 感
- 动作制作优先级（codex 建议）：呼吸眨眼 idle > 翻页 > 喝咖啡 > 趴睡 > 挥手 > 倒咖啡（双手+液体最难，后置）
- **零成本在场**：presence 的一切视觉不要求对方做任何操作——应用开着形象就在
- 角色三层动作缺一不可（避免「带眼睛的家具」差评）：①随机微动作 ②对用户行为的反应（点击/对方打字）③偶发主动行为（伸懒腰、看向屏幕外）
- 尊重 `prefers-reduced-motion`：粒子与视差可降级

## 7. 声音：ASMR 音景

- **分层混音**：环境层（雨声/壁炉/风）+ 音乐层（lofi）+ 反馈层（点击/翻页微音效），各层独立音量
- **必须记住上次组合**（Spirit City 最大差评就是不记忆）
- 默认静音启动（网页 autoplay 策略 + 礼貌）；房间模板可带默认音景预设
- 远期若面向公开用户/主播：曲库需直播安全（版权）

## 8. UI 风格：玻璃拟态薄壳

- **场景是主角，UI 是薄壳**：默认态只有极窄玻璃 rail（home/日历/心愿/设置）+ 物件热点微光
- 热点默认静止低透明，hover/键盘焦点才呼吸——**不许六个点同时闪**（找物游戏感）
- 日记以场景同类棕色日记为原型，桌面 1440×900 中外框 1040×670、中心 720/450；用户明确允许遮挡角色，覆盖旧“偏右下避让”规则。旧纸/叠页、手写风墨色与独立羽毛笔已实施；小屏单页，不缩字硬塞双栏。翻页使用真实图文与旧纸组成的三维正反纸面：立起绕书脊翻过，不用独立文字淡出；底下新页同步显露，已加载中间页保持清晰。阅读时雨不停播。拿起/收回和羽毛笔交互仍待办，见 `ai/design_system/cinnaglass/journal-room-object/turn-implementation.md`。其他功能复用材质家族而非强行套书本形态。
- 样式四载体契约（继承 v1 工程体系）：全局 token+原子类（cinnaglass.css）→ 组件 `<style>` 块（域前缀 `.tl-` `.pw-`…）→ 页面 CSS Module → shadow DOM（image-slot）
- 现有健康原子继续用：`.glass` `.btn-primary` `.chip-accent` `.field` `.sw` `.card` `.modal` 系、`icons.tsx`、`<image-slot>`
- token 双轴（已定稿）：`[data-mood]` 管时辰明度、`[data-glass]` 管材质 blur/saturate，两轴不抢一件事

## 9. 工程验收标准（实现前三项硬验证 + 惯例）

1. 主画面缩到 960px 宽：角色表情仍可读
2. 小窗真实 640×400：眼睛/嘴线宽不糊（OS 125%/150% 缩放下单独验收）
3. 夜档最低亮度屏：蓝耳轮廓与 rail 图标不消失
4. **对比度不心算**：headless Chrome 截图 + 像素采样实测（v1 惯例，工具链见 design_system `_shots/`）
5. 性能红线：场景静止时 GPU 不持续满跑（`frameloop="demand"` / 按需渲染）、失焦暂停、24–30fps 节流——「挂一整天」的软件 3% CPU 都会进差评

## 10. CSS 工程坑备忘（v1 踩过的，别再踩）

- **CSS 变量别名在声明处求值**：`:root{--glass-text:var(--shell-text)}` 会冻结在基准档——必须在 `[data-mood]` 宿主上重新声明别名（cinnaglass.css 的 re-alias 块删不得）
- **改半透明壳透明度 = 同时改文字对比度**，两者必须一起复测
- 验证页图标用 `currentColor` 描边，**不用 emoji**（emoji 自带颜色造成对比度假阳性）
- 比稿/验证背景必须贴真实场景亮度，浅色文档底上评估透明度严重失真
