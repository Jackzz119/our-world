## 整体风格

**镜头就是你，桌子对面坐着你在乎的那个人。** 画面里只有对面一个人，正对着你；你出现在前景的手、袖口和杯子里。每个人的屏幕上都是对方，是同一张桌子的两头。角色是对方本人的形象，不是 AI 陪伴角色；对方真实在做什么，角色就在做什么。

| 维度       | 当前规范                                                                                                                                                                                                                                                                                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 构图与镜头 | 第一人称固定机位；对方半身居中偏上，桌子挡住下半身；前景是自己的手、袖口和杯子；前中后景分明、浅景深；只做小幅视差，不做自由镜头                                                                                                                                                                                                                  |
| 画风       | 二次元 CG 厚涂，接近抽卡游戏主视觉的完成度：半写实比例（不是 Q 版，也不写实）、细线稿、柔和赛璐璐加绘画渐变、暖色透光皮肤、细致发丝高光                                                                                                                                                                                                           |
| 光         | 实景光源做主光（台灯、炉火、红色安全灯），再配一道反差的环境光或轮廓光（窗外城市、雨夜冷光）；泛光、散景；每种时辰和天气的主光方向与色温明确不同                                                                                                                                                                                                  |
| 房间       | 一个房间 = 一个功能 + 一个小游戏；十个房间是十个真正不同的地方，各有自己的色调、光和标志物，不是一套公寓换颜色                                                                                                                                                                                                                                    |
| 互动       | 动手 → 对面有回应 → 结果留在对方那边 → 变成回忆；对方不在线也能玩，只加不减                                                                                                                                                                                                                                                                       |
| UI         | Cinnaglass 磨砂玻璃继续沿用，2026-10-01 换成更实的深玻璃（硬描边、深投影），不再融进场景；2026-10-02 暖瓷浅色正式实装，和描金暗夜一起在设置里可选；场景和人物优先：**场景伴生**的功能（房间、聊天、一起听、回忆入口）手机上从底部升起只盖我这边、导航展开成托盘的标签栏，桌面贴边停靠；**内容页**（日记、照片墙）手机全屏、桌面正中，房间压暗退后 |
| UX         | 游戏 app：任何交互都有反馈（按下缩、放开弹、成功有小庆祝），低动效模式兜底；动效用苹果的弹簧模型，拖动跟手、带着手指的速度回弹（2026-10-02）；手机一次只开一个窗口、关闭永远有按钮；弹层先画好再动、动的时候房间暂停（2026-10-02 掉帧修复）；每种已采用的交互有流程、状态、动效数值和录屏，见 [UX 参考](uiux/cinnaglass/ux/ux.md)（§0 产品分层）  |

### 铁律（违反即返工）

1. **对面是真人**：角色的每个主动动作都来自对方的真实状态，或 TA 亲手留下的东西（录音、便条、送来的咖啡）。人不在就是空椅留痕，不装作在；「睡着了」只由对方主动设置，不靠断线猜测。
2. **只做正反馈**：植物不会死，没有连续打卡、排行和惩罚。
3. **互动长在房间和物件上**：场景里的东西是仪式和玩具，不做 UI 功能的重复入口；完整功能仍在 UI。
4. **可点物件不画光圈、描边、光环或定位针**：提示只用细小星芒、物件自身的待机动作（蒸汽、转盘、摇叶）或桌面端手形光标；hover 只改亮度、速度、透明度等参数，不换图。
5. **部件必须由生成产出，不后抠、不手修**（2026-09-06 用户定规）。
6. **死物吃画里的光，活物吃场景的光**（2026-09-07 用户定规）：静物保留原画光影；会动的部件和角色由引擎给光（tint、光层）。
7. **人物原创**：不像任何现有 IP；提示词不写在世艺术家或工作室名。

## 维护规则

- **设计系统只放最新一期**（2026-09-27 用户定规，Monet 技能「换期与档案」）：新一期定下后，上一期的旧概念、旧稿与旧素材移到 `arts/archive/<期>/` 留档，只留一期；两期以前的资料尽量删除。档案不作开发参考源。
- **原始生成批次不入库**：`codex-visual` 的时间戳批次目录（草稿、未选图、工具日志）留在本地；定稿图、提示词与制作注记整理进常驻文档或 concept 后入库。
- **待确认的比稿**放 [视觉工作台](codex-visual/README.md)，用看样页展示；方向认可后，Monet 把定下的部分写进领域文档，UI Tailor 把定稿的界面写进 `uiux/`，交互写进 [UX 参考](uiux/cinnaglass/ux/ux.md)（流程、状态、动效、录屏，不只 token）。
- **美术图不在会话里自己生成**（2026-09-30 用户定）：需要新素材时先占位，等用户在机器上装好 Codex，再用 `codex-visual` 出图。要图的地方写进 [要图清单](codex-visual/art-requests/art-requests.md)（在哪、现在什么样、要什么、怎么接、怎么验），代码里用 `ART-REQUEST` 注释标出接入点。
- **看样页常驻**（2026-10-02 用户定）：[UI/UX 看样页](uiux/cinnaglass/ux/index.html) 是 agent 和用户查看设计的参考，只放这一期在用的界面；界面改了就重拍、替换，旧图不留在页上。发布版用 `node scripts/build-review-page.mjs <输出目录>` 生成（已自动内联批注层，见技能 `annotated-report`），发布时 `capabilities` 带 `{comments: {}}`，发布到同一个地址。
- 每次设计变化同步本页和受影响的领域文档，并运行 `node scripts/check-design-system.mjs` 检查链接与图文。
