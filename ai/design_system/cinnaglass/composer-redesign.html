B · 上传区

展开态的图片上传位 —— 三方案已选 V1

现状 62×62 方块塞「图标+标题+副行」三层竖排必然剪裁。三案均为同 token 比稿：
V1 · 宽条拖放区（横向一行，文字永不剪裁）✓ 我的推荐
拖放目标越大越好命中（Fitts 定律）；文案横排完整呈现；选图后整条变成宽幅预览，所见即所得。
分享一张此刻的照片 · 拖进来，或 选择文件
V2 · 大照片位（左置 118px 方块）
文字竖排能放下但局促；拖放命中区小；与文字并排压缩了 textarea 宽度。
分享照片
拖入或点击
V3 · icon-only 小块（附件式）
最省空间，但拖放不可发现（没有文案暗示），且「照片是回忆的主角」的产品定位下太弱势。
C · 发布 CTA

发布按钮 —— 鼓励记录的关键触点已选 B1

UX 依据：CTA 文案「动词 + 情感价值」优于抽象系统动词（「发布」是平台向的技术词）；与折叠态入口「记录此刻的我们…」形成同一句式的呼应；发光渐变 + hover 浮起给「值得一按」的分量。

B2 · 蓝粉渐变（♥ 与作者粉撞语义）
