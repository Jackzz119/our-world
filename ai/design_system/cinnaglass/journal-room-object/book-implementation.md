# 棕皮旧纸书本 · 静态美术实装

2026-09-07。本轮按用户批准稿实施书本，不改已经认可的导航。**静态美术已接入本地，等待用户实景审美验收；不把工程检查通过等同于逐像素完美复刻。**

后续状态：同日已接续实施 [竖直翻页、连续翻阅与阅读时雨不停播](turn-implementation.md)。本文保留静态轮当时的检查记录；下文“下一轮”事项以新报告为准。

## 1. 这轮看到的变化

书本在桌面窗口中心放大为 1040×670 左右。棕皮、缝线、叠页、书脊与旧纸纤维来自同一张空白书本素材，不再用纯色矩形代替。日期、标题、正文、页码都是实际文字，覆盖在无字纸面上；用户仍可选中、复制自己的回忆。

正文采用暖褐墨色与本地手写风字体，使用 multiply（把墨色与下面的纸色相乘，让纸的明暗参与字色）和极轻的墨边，避免像悬浮标签。日期没有底板；条目只有淡中性细线范围框，没有蓝/粉左边线。默认头像使用批准稿里的原创角色肖像；用户自定义头像保持原样。照片以同源旧纸角固定，短文放在照片下方。

羽毛笔是独立透明图片，只作装饰，不接收点击。原来的“写一页”文字入口保留，仍打开原草稿编辑器。

## 3. 材质和版式登记

视觉签名：栗棕皮革、蜂蜜磨边、旧米纸、暖褐墨、象牙羽毛。轻微纤维和磨损留在纸里，不盖住正文，不铺满彩色条目底板。

- 书本底图：1536×1024，外部透明。运行时校色为 `contrast(.84) brightness(.95) saturate(1.12)`，主要压回生成稿过亮的纸面。
- 正文墨色 `#594126`，日期 `#604A30`，辅助字 `#735B3B`；范围框 `#946A3438`。纸色以纹理图经真实 CSS 合成后的像素为准，不把单一色块伪装成完整材质。
- 桌面标题 26px、日期 21px、正文 17px，正文行距 1.65；页内左右留白各 34px，上/下保留 86/70px，条目之间 22px。中屏与小屏保持 18px 正文，短窗口 16px，不为硬塞双页把字无限缩小。
- 全书在桌面中心，不为避让角色偏移；窄屏/矮屏单页在中心上移 22px，为底部导航留空间。
- 作者身份只落在头像、轻微蓝/粉光环及可访问名字上。没有固定“我在左、你在右”的作者分栏；真实回忆依旧按旧→新流经左右页。
- 三种时辰使用同一实体书材质，只有后面的场景及已经完成的导航随光变化。本轮未实现书本的动态受光，也未迁移其他功能弹窗。

本地字体选用 [霞鹜文楷 Lite 官方项目](https://github.com/lxgw/LxgwWenKai-Lite)，保留 OFL 许可证与完整字形集合。WOFF2（适合网页加载的字体压缩格式）为 5,269,840 字节，约 5.27 MB；本轮优先保证真实中文内容可用，分块字体与低带宽首屏尚未验收。加载完成后重新量字分页，避免替换字体导致文字挤出纸面。

## 5. 处理过的问题与验收边界

生成空白书时第一次把棋盘画成了背景，第二次透明化生成也失败。最终只移除第一张图上与外沿连通的中性背景；书内原始 RGB 在压缩前不变，所有原图保留。详见 [完整生成与处理记录](book-prompts.md)。

首次实景还发现页码压在封皮、小屏日期与目录太靠外、正文比参考偏大导致短句换行，均已调整并重新截图。头像、页码和日期仍为真实组件，不把整张设计稿贴成不可用的页面。

当前仍有明确边界：生成的空白书是参考驱动的重建，不是对原图逐像素修补；纸边纹路、羽毛形状和照片纸角不会完全同像素。不同真实内容也会改变页数和行数。用户要求的“完美还原”最终需要实景审美确认，本报告不以一个百分比自证。

下一轮再做：字、日期、照片与纸一起弯曲的翻页；跨页连翻；桌面拿起/收回；羽毛笔交互。现有页码/目录只直接换页。`WorldPage.tsx` 仍传入 `active={screen === null}`，阅读态场景会停绘，因此雨持续播放也仍是待办，静态雨景截图不证明它已实现。
