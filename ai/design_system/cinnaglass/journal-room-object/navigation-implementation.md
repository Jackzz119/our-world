# 导航还原 · 实现与验证

2026-09-07。状态：导航已接入本地产品并完成下列检查，待用户看实景；未部署。批准参考：[桌上的同一本日记](room-journal-concept.png)。

本轮只实现导航。用户明确认可稿中发光，因此保留明显暖光，覆盖旧报告「下调光晕」的建议。日记本、其他功能弹窗和场景暂停逻辑不在本轮变更内。

## 2. 材质裁决

单靠均匀渐变与噪声，第一版出现了「整条灰雾」的问题。因此选用混合做法：

1. 真实场景透射：小幅背景模糊，保留窗帘与房间明暗，不把底图烘进 UI。
2. 中性烟色底：以当前 mood（时辰档位）选择烟色厚度和反射色，不使用固定绿色。
3. 生成细纹：仅叠加透明的浅/深细纹；原始灰底已去掉，不再覆盖房间。
4. 局部细反光：1 px 的遮罩边缘沿周长分段变亮、变暗，不做等亮描边。
5. 图标亮光：矢量线条自身发光，下面另有一层柔软的琥珀光斑。不是给整张方形图加亮。

材质唯一实现位置：`src/themes/cinnaglass/shell/navigation-glass.css`。变量只存在 `.rail-wrap` 内，不修改共用 `--cg-*` / `--craft-*`，避免把所有纸页和旧弹窗一起改色。

| 实际时辰 | 烟色底 RGB / 基础透明度 | 细纹强度 | 图标静止颜色 |
| --- | --- | --- | --- |
| 深夜 night | 76, 69, 58 / 0.17 | 0.34 | #EED5A8 |
| 黄昏 golden | 43, 36, 28 / 0.52 | 0.36 | #FFF0D0 |
| 暮色 twilight | 63, 64, 72 / 0.19 | 0.34 | #EEE0C6 |

以上透明度只指底色这一层，**不是合成后的整条不透明度**。黄昏窗帘比夜间亮很多，初版图标采样只有约 2.22:1；增加该档烟色厚度后，最终这一轮最低核心采样为 3.14:1。不是把黄昏直接套成夜色。

背景模糊 2.4 px、饱和度 0.7；反光边缘分段透明度约 0.02–0.72。未来 day / morning 留有中性回退参数，但现有书房只有上述三档；没有宣称真实白天或花园已经验收。

## 3. 大小与交互

桌面条件：视口宽至少 768、高至少 600 px。导航宽 74、高 384、圆角 25；离左边 38 px，垂直居中。主按钮 54×54，五个入口依次为房间、聊天、一起听、工具、设置，不再叠一个无功能的顶部徽标。聊天未读粉点保留。

窄屏或矮屏：转为底部 292×62 的横条，离底 10 px；五个 48×48 触摸按钮。房间和工具小菜单向上展开，尺寸受视口约束。

| 状态 | 完整反馈 |
| --- | --- |
| 静止 | 暖色细线，轻接触阴影；无持续发光动画 |
| hover，鼠标停留 | 图标提亮、线条光晕与圆形光斑在约 200 ms 内出现 |
| pressed，按住 | 按钮缩至 94%，光收紧且更亮；松手恢复 |
| 菜单打开 | 保留较弱暖光；移开鼠标后仍能看出哪个菜单开着 |
| 键盘焦点 | 暖色轮廓与发光；Escape 收起小菜单 |
| 禁用 | 变淡、不能操作、不发光 |

触屏实测发现 Chromium 按住时 `:active` 没有生效，所以添加了按键自身的指针状态。手指按下 → `data-pressed` 置为真 → 显示按压亮光；松开、移出、取消触摸或失去焦点 → 清掉状态。发光不依赖鼠标悬停。

房间和工具小菜单复用同一材质家族：为了读清文字，模糊增加到 8 px、底色透明度至少 0.5；不是直接照搬窄导航的薄玻璃参数。工具开关保留原有行为，补回可移动滑块，收敛成暖色，不再残留旧版亮蓝整块。点外关闭由外部指针事件判断，不再放一个可能扩展页面宽度的透明遮罩。导航使用视口固定定位，不跟着其他内容造成的页面滚动偏移。

用户点击入口 → 原组件原回调打开对应功能；本轮没有增加网络写入逻辑。纪念日、音乐条等开关仍使用原来的个人显示状态；测试切换两次恢复。没有发帖、聊天、上传图片或改共享数据。

## 4. 验证证据

执行脚本：`scripts/check-navigation.mjs`；输出：[原始检查结果](navigation-verification/results.json)。截图使用真实应用加载的 CSS 与纹理，不由设计稿重新生成。

- 三时辰：静止、悬停、按住、菜单打开、键盘焦点均截图；鼠标移开后打开态暖光仍在。
- 四尺寸：1440×900、960×700、640×400、390×844；导航位置、大小及房间菜单边界断言通过。
- 五个主入口、禁用装扮、工具开关切换与恢复、照片墙打开与关闭、Escape 和点击外部通过。
- 触屏模拟：390×844，真实粗指针/无悬停模式；按住亮光达到 1，缩放为 0.94；松手和取消触摸状态清除，菜单打开/关闭通过。是桌面 Chrome 的触屏模拟，未冒充真机测试。
- 减少动态效果偏好：过渡时长为 0；禁用透明的回退样式已提供，未做 Safari 与真实系统偏好的专项验收。
- 无浏览器未捕获脚本错误；共用纸色仍为 #D8CDBA，未被导航覆盖。
- 静止图标核心像素的第 10 百分位对比度：深夜最低 4.52:1、黄昏 3.14:1、暮色 3.76:1。采样是隐藏图标前后截图配对，只检查亮线核心，不等于全像素或全产品无障碍认证。

多轮复核中的不通过项均已修正再跑：灰底纹理把玻璃变雾板；黄昏图标不清；外部遮罩及页面横移风险；触摸按住没有亮光；工具菜单旧蓝色与缺少滑块。没有把首次截图当成最终验收。

构建：改动 TSX 的 ESLint 检查通过；Vite 打包通过。完整 TypeScript 类型构建仍被既有 `shell/chat-card.tsx:10` 的 `Msg` 导入错误阻断，本轮未改该聊天文件。Vite 仍提示主包超过 500 kB，不是新增导航专用包告警。

未覆盖：真实触屏硬件、Safari、真实花园/白天房间、低端设备帧耗、双账号业务发送。没有部署。最终审美确认由用户在真实场景查看后给出，不以自动脚本代替。

## 5. 文件与复用边界

- `shell/rail.tsx`：原入口与菜单保留；五图标排列、键盘/指针反馈与关闭行为。
- `shell/rail-icons.tsx`：五个导航专属线性图标，不改全项目图标体系。
- `shell/navigation-glass.css`：尺寸、三档材质、局部反光、全部反馈状态与窄屏规则。
- `arts/ui/navigation/`：原生成图及来源登记；`public/ui/nav/`：当前采用的透明纹理与清单。
- `scripts/pack-navigation-texture.mjs`：把中灰偏差转成透明细纹，编码为约 298 kB 的 WebP；不裁切或替换房间。
- `scripts/check-navigation.mjs`：以上浏览器检查及证据输出。

其他弹窗**应在后续按同一个材质家族归类**：工具外壳复用中性玻璃、随光细边与细纹；书页和照片等内容物件保留自己的实体材质。不能把整本日记都变玻璃。当前只迁移导航自身的房间/工具菜单，其他功能弹窗继续保持原样，避免超出用户本轮范围。
