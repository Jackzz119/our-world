① 调研基线

两条外部依据，指向同一个方向

大耳狗官方形象：白色身体占绝对大面积，天蓝只出现在眼睛/logo，腮红粉是唯一暖点缀 —— 白是主角，蓝是灵魂，粉是表情。 Apple Liquid Glass（WWDC25）：玻璃材质只留给导航层；内容要坐在可读的实底上；玻璃叠玻璃是明确反模式；玻璃在浅色内容上要变亮、前景文字要变深。

#FFFFFF大耳狗本体白 · 主面积
#59C5ED官方天蓝 · logo/眼睛
#BEE1FA浅云蓝 · 辅助底
#FDD5E7腮红粉 · 点缀
#2F9AD3深天蓝 · 按钮/强调
#22335A深海军蓝 · 正文字

③ Token 落地对照

方案 C 的 token 变更清单（cinnaglass.css）

三套玻璃风格保留（cloud 更瓷白 / sky 保留淡蓝但整体提亮 / twilight 夜用不动大格局），下面是默认 + sky 的核心变化。新增 --glass-paper 给内容层用。

--glass-bg .74白旧 .66 白 / sky 蓝染 .56
--glass-bg-2微蓝白 .52，替代蓝染
--glass-paper 新增内容卡实底白 .92
--glass-text#2A3A5E → #22335A 加深
--glass-sub62% → 70% 提对比
--accent#7CC6EC → 官方 #59C5ED
--accent-deep#4FA9DC → #2F9AD3
--blush#F8D7DF → 官方 #FDD5E7
纪律（写进 ui-system 文档）：玻璃只给外壳（sidebar、modal、HUD 浮窗、dock）；壳内的内容面一律 --glass-paper（列表卡、设置行、气泡、输入框）；玻璃壳内不再套第二层玻璃。
落地修正 v2（2026-07-12 实景校准，以此为准）：比稿的浅底背景骗了透明度——真实场景偏深紫，半透明白压上去发灰。最终 token：壳提到近实底白（默认 .94/.87，sky 带一丝天蓝 rgba(240,249,254,.94)，saturate 降回 1.5）；--glass-paper = 纯白 #fff；新增三个 token 承担「白底上的分层」：--glass-line rgba(33,57,92,.1) 发丝分隔线/卡边、--glass-hover rgba(216,239,250,.6) 浅天蓝悬停、--glass-active rgba(174,223,242,.6) 天蓝选中。白当底，蓝分层——白色元素之间的间隔全部交给蓝，不再靠白色边框（白上白隐形）。
