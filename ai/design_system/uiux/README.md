# UI/UX 目录说明

当前界面与交互见 **[uiux.md](uiux.md)**；整体风格见 [design-system.md](../design-system.md)。

- `uiux.md`：当前 UI 地图及主题/组件链接。
- `interaction.md`：当前与目标交互契约，旧动画表有明确状态。
- `cinnaglass/ui-system.md`：当前主题图文规范；`ui-system.html` 为真实参数/组件预览。
- `cinnaglass/decisions.md`：项目 UI 决定，不能移入技能目录。
- `research/`：有价值的 UI 调研、比稿和来源；历史稿不作为当前批准。

UI Tailor 更新常驻资料，Monet 检查整体链接与视觉统一。项目报告默认在 session 汇报，不逐轮创建 report 文件。
