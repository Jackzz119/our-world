## 用户已明确的边界

- 日记是场景桌面上那个可点击的棕色本子被拿到眼前，颜色、封皮、纸边和丝带属于同一件物品。不是角色手中的蓝色书，也不继续用苔绿皮。
- 打开后**严格居中、比上一版大**。不再为让出角色面部将书推到右下。
- 日记遮挡场景不等于暂停世界：雨、角色呼吸、钟和其他正在运行的环境动画继续，声音也不因打开而中断。
- 工具 UI 是有细微纹理与环境反光的透明材质；整体克制，色温受当前时辰影响，不统一刷绿。
- 本轮只出设计稿与说明，不修程序、不替换场景图、不安装新依赖。

## 1. 现在的翻页究竟是什么

本地 `journal-book.tsx` 用 `page-flip@2.0.7` 的 HTML 模式。`journal-layout.ts` 先根据真实文字尺寸分成网页页片，再交给翻页库。

查看本地依赖 `node_modules/page-flip/src/Page/HTMLPage.ts:103` 的 `drawSoft`：它给整页设置旋转、位移和多边形裁切，再通过阴影制造翻折印象。**这是平面翻折近似，不是柔软纸张的连续弯曲。** 正文的确是页节点的子元素，会随其旋转；不能说所有字都完全独立于页片。但是它不会随想象中的曲面连续变形，所以字与纸的触感不一致。另有 `screens.tsx` 标题以及书外固定工具不属于翻动页，日期/标题在页与壳上混合分工又加重了脱离感。

上轮只核对了翻页最终目的、连续页变更、拖角、溢出等，没有用慢动作追踪文字、纸纹、照片角是否贴合。这个验收缺口由设计与实现方承担，不应归因于用户期待过高。

其他代码证据：

- `diary.css` 的封皮主要是三色渐变加虚线边，纸是固定暖灰底加极低强度程序噪声；缺少真正对应的皮革纹理、使用痕迹和纸边资产。
- `rail.tsx` 使用单个 `--cg-panel` 底、均匀描边，相关值固定偏绿，没有按时辰重新设计局部反射。
- `WorldPage.tsx` 传入 `active={screen === null}`，`room-scene.tsx` 在不 active 时调用 `app.stop()`。日记打开后整个场景绘制暂停，雨自然也会停。这是明确的代码原因，不是猜测。

## 2. 新稿的设计裁决

视觉签名：**桌上的旧皮日记，被轻轻拿到眼前；窗外的雨没有停。**

### 书：有来历的物件，不是着色面板

参考真源为 `public/rooms/study/night.png` 与 `golden.png` 中桌面的开放日记。保留其棕色封皮、暖褐纸边与朴素丝带。放大后补足同类材质细节，而不是凭空创造新颜色。

五个主色族：栗棕皮革、蜂蜜色磨边、旧米色纸、深褐墨、无彩烟玻璃。作者蓝/粉只用于身份小标，不占大面积。

封皮需要细密不均匀皮纹、转角磨亮、脊部压痕和窄缝线；纸页需要纤维、叠层、轻微不齐的边缘和比正文区稍旧的外沿。陈旧感不等于脏：正文区安静、无大片污渍，不加藤蔓、宝石、烫金花边。

左页依旧是独立头像与极淡中性范围框；日期印在纸上，不作悬浮标签。右页照片用纸角固定；完整记录按时间跨页，不能把作者固定分到左右列。图中排版只是示例，实装必须容纳任意真实图文。

### 构图：由用户本轮决定覆盖旧避让规则

桌面建议基准：1440×900 中，打开书本外框约 **1040×670**，中心为 **720 / 450**，左右与上下都严格居中。相较上轮 760×430 明显放大。导航独立在左侧，不参与书本居中计算。其他尺寸暂按可用宽高等比约束，窄屏仍可单页；不能为凑双页把字缩小。

生成板主画面含展示偏差，不将生图的几何坐标反写为实现坐标。实际以以上居中数值为准。

### 开场：同一个物件的连续动作

建议总长 650–850ms：从实际桌面热点位置抬起 → 放大并转正到屏幕中心 → 书页轻轻展开、落稳。不是一个已经排好内容的弹窗缩放进来。关闭沿反向轨迹收回；背景不中断。

注意场景里的目标已经是打开状态，因此取景阶段应承接已有开合角度，不能瞬间替换成陌生的合书。原图中的本子是烘在底图里的，将来要生成同源分件与移除本子后的底图，才不会出现桌上一本、手里又一本的穿帮；这轮没有制作或替换这些资产。

### 导航：同一块玻璃受不同的光

- 日光：低饱和中性雾色，让背后的场景色透进来；不是乳白实板。
- 暖灯：局部边缘受琥珀光，壳中央仍中性；不是整条棕金或绿色。
- 夜雨：烟灰本体、少量窗边冷蓝与灯边暖反射；避免大面积蓝紫面板。

层次来自模糊的场景透射、细微不均匀纹理、两三段局部细反光和柔软投影。描边不应整圈同亮；远离光的边缘弱到接近消失。选中图标只轻微提亮与浅凹面，不用霓虹光圈。生成稿的选中光晕仍偏强，落地前应下调。

## 3. 翻页的新技术方向（仅提案）

建议先做一个独立的单页动作样板，不直接再次大范围改 UI：

1. 将同一页的纸纹、日期、文字、头像、图片绘制成一张页面图。
2. 把页面图贴到可弯曲的细分网格上——可以理解成把纸切分成许多相连的小片，一起弯，印在其上的字自然一起弯。
3. 翻动期间只显示这份页面，不让另一份直立文字叠在其上；停下时回到清晰、可选字、可访问的内容层，前后必须位置一致。
4. 多页跳转让真实纸叶按方向连续翻过；缓存附近几页，不一次缓存全部历史。减少动态效果时直接切页。

项目现有 PixiJS 的网格系统支持顶点和纹理映射控制，官方文档有曲面/变形能力说明。这使复用现有引擎成为合理的先行研究方向，但**不是已有开箱即用的翻书控件，也不代表本项目方案已经验证**。[PixiJS 官方 Mesh 文档](https://pixijs.com/8.x/guides/components/scene-objects/mesh)

风险闸门：中文字体清晰度、跨域签名照片绘制、首帧与收尾对位、编辑时输入法、页背与阴影、同时下雨时帧率。若纹理路径不能可靠处理真实照片/文本，不应为了保留技术选型牺牲效果。

## 4. 这张稿的独立复核

通过方向检查：棕皮同类物件、显著放大接近居中、旧纸与层叠边缘恢复、头像范围框无彩色左边线、三种时辰导航不再统一绿。
