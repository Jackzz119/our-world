## 2. 材质与版式契约

视觉签名：栗棕皮革、蜂蜜磨边、旧米纸、暖褐墨、象牙羽毛；纤维磨损不盖正文，不铺彩色条目底板。

- 底图 `book-open.webp` 1536×1024，外部透明；运行时校色 `contrast(.84) brightness(.95) saturate(1.12)`，压回生成稿过亮的纸面。
- 墨色：正文 `#594126`、日期 `#604A30`、辅助字 `#735B3B`、条目范围框 `#946A3438`（淡中性细线；日期无底板，无蓝/粉左边线）。正文用 multiply（墨色与下方纸色相乘，让纸的明暗参与字色）加极轻墨边。纸色以纹理经真实 CSS 合成后的像素为准。
- 桌面标题 26px、日期 21px、正文 17px、行距 1.65；页内左右留白各 34px，上/下 86/70px，条目间距 22px。中屏小屏正文 18px，短窗口 16px，不为硬塞双页无限缩字。
- 全书居桌面窗口中心，不避让角色；窄屏/矮屏单页在中心上移 22px 给底部导航留空间。
- 日期/标题/正文/页码是可选中复制的真实文字，覆在无字纸面上；默认头像用批准稿原创角色肖像，自定义头像原样；照片以同源旧纸角固定、短文在其下；羽毛笔为独立透明装饰图，不接收点击；原「写一页」入口保留。
- 作者身份只落在头像、轻微蓝/粉光环与可访问名字；无「我在左、你在右」分栏，回忆按旧→新流经左右页。
- 三时辰共用同一实体书材质；未实现书本动态受光，未迁移其他功能弹窗。

字体 [霞鹜文楷 Lite](https://github.com/lxgw/LxgwWenKai-Lite)，保留 OFL 与完整字形集；WOFF2 5,269,840 字节（约 5.27 MB）。加载完成后重新量字分页，避免换字体把文字挤出纸面。分块字体与低带宽首屏未验收。
