M · 弹簧动效

你说 toggle 的横移条有一点弹性，可往上拖托盘时很重、拖不动。查下来是三个原因：

  • 只有手柄和标题条能拖，推下面的内容没有反应；
  • 拉过顶部以后阻尼太重：多拉 100px，托盘只跟 25px；
  • 松手时托盘先停住，再用固定的 460ms 曲线走完，手指的速度丢了。

这一轮照苹果的做法改了（WWDC23「Animate with springs」和 WWDC18「Designing Fluid Interfaces」）：

  • 弹簧只看两个数：感觉多长（duration）和回弹多少（bounce）。质量 1，刚度 (2π / duration)²，阻尼比 1 − bounce。CSS 里的曲线就是这些弹簧采样出来的 linear()，时长取弹簧真正停稳的那一刻。
  • 哪儿都能拖：移动 6px 才算拖，在那之前按下还是按下。按钮和卡片点一下照旧，拖完松手也不会误点；拉满时能滚的列表自己滚。
  • 1:1 跟手，过顶有橡皮筋：用 iOS 滚动视图的系数 0.55。500px 高的托盘多拉 100px 会跟着走约 50px，越拉越紧，但不会拉不动。
  • 看往哪儿甩：按 iOS 的减速率 0.998 推算手指会把托盘甩到哪儿，就停在离那儿最近的位置（拉满 / 半开 / 收起）。弹簧从手指的速度起步，所以不会顿一下。
  • 半路能接住：回弹到一半再按住，托盘就停在手指下面，不会跳。
  • 每根弹簧各有用处：标签滑块和视图切换用 bouncy（回弹 4.6%，就是你说的那点弹性），放开按钮和开关圆钮用 pop（10.7%），托盘升起用 smooth（不回弹），面板和卡片用 snappy。

四条曲线

smooth 621ms · 不回弹 · 托盘、内容页
snappy 504ms · 0.6% · 面板、卡片
bouncy 692ms · 4.6% · 标签滑块
pop 667ms · 10.7% · 按钮放开、开关

竖线是终点。四个球同时出发：smooth 不过线；snappy 几乎看不出回弹；bouncy 过线一点再回来，就是你在横移条上感觉到的那点弹性；pop 弹得最明显，只用在按钮放开这种很短的动作上。

要图的地方

界面里还有 5 处在用占位：纸、胶带、软木都是 CSS 画的，海报是概念图的裁切。我没有自己生成图，而是把每一处在哪、现在什么样、要什么、怎么接、怎么验都写进了 要图清单，每组还附了可以直接贴给 Codex 的英文 brief。代码里搜 ART-REQUEST 能找到每一处接入点。

交接给出图的 agent：在你的机器上用 codex-visual，一次委派一组：R1 海报 → R2 纸和软木 → R3 胶带 → R4 空状态。共用的要求：不写字、不画人脸、原创；图由生成直接产出，不后抠、不手修；回忆页的材质不随时辰变。出完先给你看，接好后在这里换成新截图。

ART-01 歌单海报 8 张

要图 · 优先

在哪：音乐托盘和停靠栏的封套（72–112px，同时印在唱片中心的圆标上）、歌单每行 44px、迷你条 40px，沉浸歌词里还会糊成整块底色。

要什么：每首歌一张方图，画歌词里的那个画面（橘子和被风鼓起的窗帘、雨窗、暖灯收音机、樱花河边、落针的唱机、海边风铃、清晨列车、结霜窗上的心）。母版 1024²，运行时 512² webp，每张 ≤ 60 KB，文件名不变。

必须：和书房同一个世界、同一种画法，8 张像一套唱片；主体放在正中，44px 时也分得清；主色就是每首的 tint。不要：字、人脸、把整张封面画成唱片，也不要再画窗外的城市。

ART-02 手帐纸纹理

要图 · 优先

在哪：回忆页所有的纸：日记页、空状态便签、写一页、软木板的月份签、日历纸。

要什么：一张无缝平铺的手帐内页纸，细长纤维加很淡的云状深浅，几乎是白色（专门用来正片叠底，颜色仍由 CSS 给）。母版 2048²，运行时 1024² 按 512px 平铺，≤ 90 KB。

必须：2×2 拼起来看不出接缝；叠上以后正文墨色在纸最深处仍 ≥ 6.5:1。不要：横格、折痕、污渍、暗角、光照渐变。

ART-03 和纸胶带 4 色

要图

在哪：日记页顶上（76×20px）、每张拍立得（54×17px）、日历纸的角。

要什么：蓝、粉、奶黄、灰绿四条短胶带（就是现在的四种颜色），两头手撕毛边，各带一种很淡的印花（细格、小樱花、小圆点、细斜纹）。半透明、自带透明底，1024×256 母版，240×64 运行时；出不了透明底就画在纯白底上，接入时正片叠底。

不要：整卷胶带、透视、投影（CSS 加）、太艳太密的印花。

ART-04 软木板与木框

要图

在哪：照片墙·软木板。

要什么：软木无缝平铺（最终颜色，平均 #ae8259，颗粒、浅色碎屑、小坑），1024² 按 512px 平铺；胡桃木画框的横向木纹长条，840×48，竖框用同一张旋转。图钉可选（5 色，带透明底），不做就保留 CSS。

不要：把照片、纸条、图钉画进纹理里；暗角和光照（CSS 有左上亮、右下暗）；512px 一格就能认出来的重复。

ART-05 空状态小插画 4 张

要图

在哪：日记、照片墙（拍立得和软木板）、相册、放映没有内容时的那张纸条，放在标题上方，96px（手机 72px）。

要什么：像主人自己在手帐里用钢笔随手画的：深棕墨线，配一两块淡水彩，留白多。摊开的空本子和钢笔；一张空白拍立得加一小段胶带；一页贴着四个相角的空相册；镜头盖着的小放映机加一卷胶片。画在纯白底上，接入时正片叠底，768² 母版，192² 运行时。

不要：厚涂、扁平图标风、阴影、彩色底、字、人物；不能比纸条的标题抢眼。

不需要出图、保持 CSS / SVG 的：图标（要随主题换色、要锐利）、放映的银幕和胶片齿孔、日历的格子、「记」字印章、玻璃的霜纹。
