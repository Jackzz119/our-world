## 0. 产品分层：场景伴生与内容页（2026-10-01 用户定，贯穿以后的开发）

用户原话的意思：音乐、聊天、房间切换、回忆入口这些是**场景伴生**功能，陪着你待在房间里，可以半开；日记和照片墙从回忆入口点开，代表要**进入非场景伴生的内容页面**——是来看内容的，所以手机上直接展开、桌面正中弹窗，不缩在一边。回忆是产品的另一大特点，入口不该是扳手。

| 层                | 现在有谁                                               | 桌面                                   | 手机                                                       | 场景                       |
| ----------------- | ------------------------------------------------------ | -------------------------------------- | ---------------------------------------------------------- | -------------------------- |
| **场景伴生**（A） | 房间、聊天、一起听、回忆入口（菜单）、时辰 / 天气      | 贴边浮窗、右侧停靠栏、导航弹出的小菜单 | 底部托盘，可半开 / 拉满；导航并进托盘的脚；关闭按钮 + 下拉 | 不暂停，TA 完整可见        |
| **内容页**        | 日记、照片墙（回忆的内容）；以后要「进去看」的都归这里 | 屏幕正中的大窗，房间压暗、虚化         | 直接全屏，从底边升起，没有半开；页头关闭按钮 + 下拉关闭    | 压暗退后，关掉内容页再回来 |
| **任务窗**（B）   | 设置、日历·纪念日、时钟、心愿单、完整聊天              | 正中小窗                               | 从底边升起、顶部圆角（2026-09-30 用户保留）                | 压暗                       |

- **手机一次只开一个窗口**：开任何托盘、内容页或任务窗，别的自动收起，不叠在一起。桌面上伴生浮窗可以同时开（聊天卡 + 停靠栏），内容页和任务窗盖在它们上面。
- **关闭永远有按钮**：拖动、下拉、Esc 都是快捷方式，不是唯一的路。
- 新功能先问「它是陪着你，还是你要进去看」，再选载体。

## 总原则

- **任何交互都有反馈**（用户：这是游戏 app，不必过分克制）：按下缩、放开弹、悬停亮、成功有小庆祝、失败轻摇；低动效模式兜底。
- **TA 优先**（场景伴生的功能）：手机上从底部升起，只盖住我这边（手和杯子），对面的人完整可见；桌面上贴边或停靠在右侧一列，不挡对方的脸。内容页是例外：进去看内容时房间压暗退后（§0）。
- **退场快于进场，动作可打断**：弹层从触发它的地方长出来；拖动跟手，甩一下就走；中途反向不跳帧。
- **低动效**：设置 → 主题外观 → 动效（跟随系统 / 完整动效 / 低动效）。位移、缩放、回弹归零，只留淡入淡出；循环和粒子关掉；房间的视差、微动、蒸汽停止。

| 名称            | 数值                                                                          |
| --------------- | ----------------------------------------------------------------------------- |
| `--ease-out`    | `cubic-bezier(0.23, 1, 0.32, 1)` 进场、退场、按下                             |
| `--ease-drawer` | `cubic-bezier(0.32, 0.72, 0, 1)` 托盘升降                                     |
| `--ease-pop`    | `linear()` 弹簧，回弹约 10%：放开按钮、小红点、印章、拍立得                   |
| `--ease-spring` | `linear()` 弹簧，回弹约 3%：面板、弹窗、标签滑块                              |
| 时长（ms）      | 按下 90 · 放开回弹 460 · 悬停 160 · 进场 260 · 退场 150 · 面板 420 · 托盘 460 |
| 幅度            | 按压 0.95（大块 0.97）· 悬停上浮 1px · 进场位移 10px、缩放 0.96               |

## 1. 手机托盘 · 定稿（2026-10-01 改：导航并进托盘、关闭按钮、一次一个）

2026-09-30 用户：从下面升起的模式很喜欢，保留。2026-10-01 用户：导航单独叠在托盘上很不自然，要融进窗口；只能拖着关有时很麻烦，要有关闭按钮；手机上不该同时开好几个窗口。场景伴生的音乐、聊天、房间、回忆入口都用同一个托盘（[sheet.tsx](../../../../../src/themes/cinnaglass/ui/sheet.tsx)），日记和照片墙不再用托盘（见 §4）。

- **流程**：点导航图标 → 托盘从底边升到半高（可见高度的一半，至少 340px）→ **导航变成托盘的脚**：同一块玻璃，导航自己的胶囊底、霜纹和描边淡掉，上面一道细线隔开 → 拖手柄或标题条上拉到全高 / 下拉收起，甩一下（> 0.11 px/ms）直接到位 → **右上角的关闭按钮**、再点同一个图标、Esc 或下拉都能收起，焦点回到入口。
- **一次一个**：开另一个托盘、内容页、任务窗或时辰 / 天气面板，正开着的托盘自己收起（[WorldPage.tsx](../../../../../src/pages/WorldPage.tsx) `others()`）。
- **回忆入口**：导航第四个图标从扳手换成「回忆」（两张叠着的拍立得，前面一张有颗心）；托盘里是三张卡：日记 / 照片墙 / 纪念日。原来工具里属于房间的东西（装扮、纪念日卡和音乐迷你条的开关、回大厅）挪到「房间」里。「回忆」二字用日记的手写体。
- **状态**：半高、全高、拖动中（超出顶部有阻尼）、收起中；托盘打开时我这边的桌面轻轻压暗，对方保持明亮；键盘弹起时托盘骑在键盘上（导航藏起）。横屏时托盘是右侧一列，导航仍是自己的条。
- **动效**：升起 460ms `--ease-drawer`，收起约 260ms `--ease-out`；导航的胶囊底 260ms 淡出 / 淡回；低动效改为原地淡入淡出。
- **手机上的 B 类任务窗**（设置、日历、时钟、完整聊天）同样从底边升起、顶部圆角，短的只盖到对方胸口以下。

## 2. 音乐主页面 · 定稿（B1 + 唱片 + B5 停靠 + B3 沉浸歌词）

## 8. 对比层次：深玻璃 · 实装 · 待看样（2026-10-01）

用户：UI 对场景来说颜色对比、层次太低，弹窗快融进场景里了，参考同类风格的优秀设计重新设计。调研的结论（来源见 [看样页](../../../codex-visual/ui-motion/review/index.html) 第 L 节）：叠在复杂画面上的玻璃要**垫一层更实、更暗的底**（Apple 的透明玻璃要求下面有压暗层，NN/g 建议 10–30% 实色衬底和 8–20px 模糊）、**一道硬的细边**加**更深的投影**让眼睛抓得住边、**不要玻璃叠玻璃**（里层用实色填充）、**进入内容就把场景压暗**（星穹铁道的全屏菜单、原神不透明的奶油色面板都是这么做的）。

- **默认：深玻璃**（[ui-system.css](../../../../../src/themes/cinnaglass/ui/ui-system.css)）：底色从导航色板里抽出来单独成 `--ui-base`（暮色 31 31 40、黄昏 40 33 27、夜 30 27 26），每个面板的不透明度在原值上加 `--ui-boost` 0.17（原来 0.65–0.74 → 0.82–0.91），模糊 12 → 18px，霜纹 0.18 → 0.1，外加 1px 暗描边 `--ui-hairline` 和更深的两层投影；导航玻璃从 0.17–0.52 提到 0.66；任务窗背后压暗 0.4 → 0.5 并虚化 3px，内容页背后 0.6 + 虚化 6px。边上的金色 / 冷色光仍跟着时辰走。
- **备选：描金暗夜**（`?look=gilded`）：近乎不透明的墨蓝玻璃（不透明度 +0.25、导航 0.86），不要霜纹，描边换成一道金线、顶边最亮。最像游戏 UI。
- **只出设计：暖瓷**（样板 `?look=porcelain`，不上线）：浅色霜玻璃配深色字，夜景上对比最强，是很多恋爱游戏的做法；要上线得把所有组件里写死的浅色字一一改掉。
- **改之前**：`?look=classic` 随时可以切回原来的玻璃对比。`?look=` 在任何页面都能用，选择留在这台设备上，`?look=default` 回到默认（[look.ts](../../../../../src/themes/cinnaglass/ui/look.ts)）。
