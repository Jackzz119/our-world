## 1. 总架构：三类载体，共用交互

用户本轮划分三类 UI，分类依据是打开后的使用方式，不是入口在导航还是物件上：

```
A 场景悬浮 UI  导航、聊天窄窗、天气、音乐、纪念卡、状态与附着菜单
B 任务界面     设置、工具/内容弹窗、完整聊天、确认与选择；账户/大厅为页面形态
C 专属物件 UI  日记等实体载体；本 session 日记冻结
```

当前导航：桌面左侧 74×384 竖条，窄/矮屏底部 292×62 横条，五入口。A 默认还包含顶部天气、纪念卡、音乐和头顶状态。旧 Discord 通栏侧栏已删除；2026-08-10 的“全尺寸底部胶囊、45s 淡出至12%、全隐藏”是未完成的历史提案，不作为当前基线。

新契约建议：A 不开全屏暗幕；B 覆盖 A 并限制后台交互；菜单跟随宿主，Esc 一次关一层、关闭归还焦点；保存失败保留输入，成功反馈必须对应真实结果。规格与响应式矩阵见 Feature §4、§7。

## 2. 功能入口地图（双通道，同一面板单一实现）

| 时间线日记 | 书桌/日记本 | — | 棕皮旧纸双页日记；窄屏单页（STYLE §8） |

| 时钟·闹钟 | 挂钟 | 无独立工具入口 | B 小窗；列表编辑存在，到时提醒待接 |

## 3. 房间切换：当前只有书房可进入

- 当前房间菜单已有书房/棋牌室/植物园缩略卡，后两项锁定；WorldPage 的换房回调尚为空。
- 右侧把手没有实际动作，建议单房间阶段收起，避免承诺可切换却无反馈。
- 横向平移、视差、1/2/3、横滑、对方所在房间提示保留为未来多房间提案，不登记为当前实现，也不在本轮定其动效参数。

## 4. 聊天体系

- **世界内**：当前消息以对方角色头顶短气泡呈现，贴纸使用文字提示；表情/贴纸驱动角色动作为未来提案，未接入现有角色系统。
- **UI 层**：当前窄窗可展开到 ChannelScreen，旧“绝不做大窗”与实现不符。建议 A 负责边看场景边聊，B 负责完整历史和复杂操作；去掉服务器式壳层，不删编辑/删除/重试/reaction/贴纸能力。文字区要稳定可读。
- **长椅仪式（招牌场景，Sky 聊天长椅原型）**：双方都在线且空闲时，两只小狗同坐沙发 → 进入「对话模式」——聊天 dock 轻轻升起、环境音渐弱、灯光向沙发聚拢。雨天+长椅+共听音乐=产品名场面（落地排 MVP 后，先做气泡+dock）

## 5. 可点击物件提示（本轮只记录边界）

当前为周期星星、hover 问候星星、物件自身微动；光环/多边形轮廓/换图方案已否决。旧“全部亮轮廓”兜底需重新设计为不依赖 hover 的提示，不再照旧实现轮廓。活物引擎与 C 物件界面本轮不改。

## 6. 历史动效提案（本轮后置，不作为新定稿）

以下保留历史参数供以后评估；当前各组件并未统一遵守。本轮只定义状态、显隐、焦点和生命周期，完成静态 A/B 体系后再单独设计动画。日记已有专属动画记录保留不动。

| 动作 | 参数 |
|---|---|
| 面板/卡片开合 | 220ms ease-out，从触发物件位置 scale 0.9→1.02→1 冒泡 + 轻微上浮 |
| 房间平移 | 320–400ms ease-in-out + 20% 视差 |
| 按钮 hover | 120ms 浮起（translateY -2px + 阴影加深） |
| 按钮点击 | spring 下压回弹（scale 0.96 → 回弹，超调 ≤4%） |
| 聊天气泡出现 | 头顶 scale+上浮 + 一次轻 wobble |

普通转场不超 500ms。日记实体翻书为明确例外：2026-09-07 接入三维竖直翻页，单张 980ms；连续每张 470ms，上张行程 38% 后接续，最多同时 3 张。文字/日期/照片/页码贴同一纸面，底下新页随遮挡显露；中途连续输入累加目标，不重播空中纸页。已载入内容不模糊，未载入历史先从目录获取，不伪造页码。关闭/缩放/打开写作收在最近跨页；减少动态效果时直接切页。参数与实景 GIF 见 `ai/design_system/uiux/cinnaglass/journal-room-object/turn-implementation.md`；拿起/收回与羽毛笔交互仍待办。

## 7. 音效体系：水滴系（与雨 ASMR 同一材质宇宙）

- **水滴 = 确认**、**涟漪 = 切换/翻页**、**湿润 soft pop = 点击**（300–600Hz 圆润起音、无锐利 attack、极少混响）
- 动森法则：音效时值与动效时值对齐（150–250ms）；同一动作永远同一声音；连续点击做音高阶梯（+2 半音递进）
- 全局音效音量随 ASMR 音景独立可调、可全关
- 候选资源：BOOM CASUAL UI（商业）、shmyak ui paper（纸质，贴水彩）、Kenney Interface Sounds（CC0 起步）

## 8. 质感与使用方式

2026-09-11 的范围是三类载体与共享控件，不再将“玻璃/纸/木/果冻”当作每个界面必须齐备的配方：

- A 采用导航同源细纹磨砂；B 建议同源厚壳加稳定内容底，具体观感待标准板确认；C 按物件决定。
- 纸可用于获准的内容本身，不把设置/日历整窗都画成旧纸；当前暖灰纸仍是待迁移现状。
    - 2026-09-07 日记覆盖 B 的灰苔封皮：棕皮旧纸、淡中性范围框、默认手绘头像、纸角照片与暖褐真文字。阅读从左页到右页再换下一组，旧→新顺序不变，不按作者分左右；窄屏单页。页码/目录触发纸面竖直翻动与逐张连翻，羽毛笔为不接收点击的静态图；“写一页”保留原草稿入口。点外/Esc 保草稿，取消才清空。其他功能纸面仍是上一轮暖灰材质，尚未迁移。
- 木、皮革、手写字体保留给真正的物件与内容；A/B 控件默认用清晰无衬线字体。
- 暖金用于操作反馈，蓝/粉用于身份，绿/红用于真实状态；不能用在线绿点作装饰。具体尺寸与状态见统一计划，不在本页复制第二份 token 表。

## 9. 反模式红线（调研 12 条全文见调研记录，此处为执行摘要）

多层菜单/重复流程 ❌｜可点物与装饰无法区分 ❌｜图标含义靠猜 ❌｜按钮少但步骤多 ❌｜玻璃底排小字 ❌｜UI 藏不干净（隐藏后残留）❌｜重要功能藏进深层 ❌｜一次平铺全部信息 ❌｜红点/成就压迫感 ❌｜设置项过多诱发把玩 ❌｜动效通胀 ❌｜hover-only 无触屏后备 ❌
