## 1. 总架构：三类载体，共用交互

分类依据是打开后的使用方式，不是入口在导航还是物件上：

```
A 场景悬浮 UI  导航、聊天窄窗、天气、音乐、纪念卡、状态与附着菜单
B 任务界面     设置、工具/内容弹窗、完整聊天、确认与选择；账户/大厅为页面形态
C 专属物件 UI  日记等实体载体；本 session 日记冻结
```

**当前**：导航为桌面左侧 74×384 竖条、窄/矮屏底部 292×62 横条，五入口；A 还含顶部天气、纪念卡、音乐与头顶状态。旧 Discord 通栏侧栏已删；2026-08-10 的「全尺寸底部胶囊、45s 淡出至 12%、全隐藏」是未完成历史提案，不作基线。

**当前契约**：A 不开全屏暗幕；B 覆盖 A 并限制后台交互；菜单跟随宿主；Esc 一次关一层、关闭归还焦点；保存失败保留输入，成功反馈必须对应真实结果。规格与响应式矩阵见 Feature §4、§7。

**所有 B 已实施的交互**（2026-09-20）：原生 `showModal()` 进入顶层，背景不可点/不可 Tab；聚焦标题，Esc/点外/关闭按钮收起后回到入口。正文滚动，折叠密码区使用 `hidden`；外观即时生效，密码关闭重开保留本次草稿，昵称保存失败保留输入可重试。改密/退出仍使用真实账号链路。照片光箱和编辑/表情层先消费 Esc，不连关父窗；确认弹层卸载也返回原触发位置。

- 房间菜单已有书房/棋牌室/植物园缩略卡，后两项锁定；WorldPage 的换房回调仍为空。

## 4. 聊天体系

- **世界内（当前）**：消息以对方角色头顶短气泡呈现，贴纸用文字提示；表情/贴纸驱动角色动作是未来提案，未接入角色系统。
- **UI 层**：窄窗可展开到 ChannelScreen，旧「绝不做大窗」与实现不符。目标是 A 负责边看场景边聊、B 负责完整历史与复杂操作；去掉服务器式壳层，不删编辑/删除/重试/reaction/贴纸能力，文字区要稳定可读。
- **长椅仪式（招牌场景，Sky 聊天长椅原型，未实现）**：双方在线且空闲时两只小狗同坐沙发 → 「对话模式」：聊天 dock 升起、环境音渐弱、灯光聚向沙发。雨天+长椅+共听音乐是名场面；MVP 后先做气泡+dock。

### 当前浮窗、草稿与真实状态

- 导航「聊天」「一起听」是开关：关闭时点开，打开时再点收起，选中高光与 `aria-expanded` 跟随真实状态。音乐收起保留迷你条与播放；组件已隐藏时从导航恢复并展开。唱片机入口遵循同一开关规则，窄/矮屏互斥仅在打开另一浮窗时执行。

- 桌面聊天左下、音乐右下，顶部天气/纪念卡分开；窄于 768px 或矮于 600px 使用底导航布局，展开聊天与音乐互斥，纪念卡避让。关闭音乐面板不暂停音频；隐藏 widget 保留播放引擎。
- 「时辰 / 天气」常驻类别文字和当前值，时钟/云图标分别表示类别；点击对应入口直接显示选项，再点关闭，两菜单互斥。天气面板附着触发钮，Esc 回到触发钮，点外关闭不抢走新焦点。实况失败显示不可用且温度为 `—`；手动天气不伪造地点温度。
- 新来信使用金亮信纸：对方有效未读消息触发，自己的新消息不覆盖未读提示；仅阅读当前世界会话才收起提示，其他会话不清掉它。点击进入聊天后沿现有已读流程更新，失败仍保留未读，删除消息不提示。信纸不另建通知或已读存储；收起聊天时焦点返回聊天导航。
- 信纸出现时桌面纪念卡向下避让、小屏隐藏纪念卡；宽度 ≤1100px 或高度 ≤700px 展开播放器时提示卡暂时让位，未读点仍可见，收起播放器后信纸恢复。
- 聊天输入法确认不发送。聊天展开关闭返回原入口；切换会话依旧清除未发送草稿，失败发送留在消息列表供重试。好友与贴纸删除使用内联确认，搜索 Enter 不提交聊天表单。
- 设置昵称失焦/Enter 保存，失败留稿；密码关闭重开保留本次挂载草稿。头像注明仅本机保存，操作可键盘触发，调整态 Esc 先完成调整。世界设置取消后恢复已保存值；日历关闭保留当前组件草稿。照片光箱 Esc 只关光箱。
- 纪念日来自世界资料，无日期时不虚构纪念日。姓名不是在线指示；本机心愿/约会/提醒明确存储范围，提醒不发通知；音乐为本机 WebAudio 音景，不代表共享听歌。
- 「减少透明效果」即时生效并保存偏好；旧卡片配色不再提供无效开关，旧存储只留给兼容消费者。此偏好不改日记。

## 6. 动效：本轮后置

本轮只定义状态、显隐、焦点与生命周期，静态 A/B 体系完成后再单独设计动画。**旧「果冻时长表」（面板开合/房间平移/按钮 hover 与点击/气泡入场五项参数）已作废**，无组件统一遵守；原参数留在 git 历史（3fd52a5 的本文件 §6），重启动画时重评。

普通转场不超 500ms。**唯一明确例外**是日记实体翻书（2026-09-07 接入三维竖直翻页）：时值、连翻队列、加载与页码真实性、「减少动态效果」行为见 [turn-implementation.md](cinnaglass/journal-room-object/turn-implementation.md)，本页不复制参数；拿起/收回与羽毛笔交互仍待办。

## 7. 音效体系：水滴系（与雨 ASMR 同一材质宇宙；提案，src 中尚无音效实现）

- **水滴 = 确认**、**涟漪 = 切换/翻页**、**湿润 soft pop = 点击**（300–600Hz 圆润起音、无锐利 attack、极少混响）
- 动森法则：音效时值与动效时值对齐（150–250ms）；同一动作永远同一声音；连续点击做音高阶梯（+2 半音递进）
- 全局音效音量随 ASMR 音景独立可调、可全关
- 候选资源：BOOM CASUAL UI（商业）、shmyak ui paper（纸质，贴水彩）、Kenney Interface Sounds（CC0 起步）

## 8. 质感与使用方式

2026-09-11 的范围是三类载体与共享控件，不再把「玻璃/纸/木/果冻」当作每个界面必备的配方：

- A 用导航同源细纹磨砂；B 已采用连续厚磨砂壳与随时辰内衬；C 按物件决定。
- 纸只用于获准的内容本身，不把设置/日历整窗画成旧纸；照片内容保留纸框。日记 2026-09-07 已迁到棕皮旧纸、覆盖 B 的灰苔封皮（材质与阅读/草稿规则见 [C 专属物件 UI](cinnaglass/ui-system.md#c-专属物件-ui)），通用表单已用受色阅读内衬。
- 木、皮革、手写字体留给真正的物件与内容；A/B 控件默认清晰无衬线字体。
- 暖金用于操作反馈，蓝/粉用于身份，绿/红用于真实状态；不能用在线绿点作装饰。尺寸与状态见统一计划，本页不复制第二份 token 表。
