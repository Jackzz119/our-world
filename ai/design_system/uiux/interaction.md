## 1. 总架构：三类载体，共用交互

分类依据是打开后的使用方式，不是入口在导航还是物件上。**2026-10-01 用户定的产品分层**：陪着你待在房间里的是**场景伴生**（A，可以半开），进去看内容的是**内容页**（手机直接全屏、桌面正中弹窗），新功能先按这条归类（[UX 参考 §0](cinnaglass/ux/ux.md)）：

```
A 场景伴生     导航、房间、聊天窄窗、一起听、回忆入口（菜单）、时辰 / 天气、纪念卡、状态与附着菜单
内容页         日记、照片墙（回忆的内容）——桌面正中的大窗，手机全屏
B 任务界面     设置、日历·纪念日、时钟、心愿单、完整聊天、确认与选择；账户/大厅为页面形态
C 专属物件 UI  棕皮书日记——2026-10-01 起是日记的一种看法（「书本」），开在回忆页里
```

**当前**：导航为桌面左侧 74×384 竖条、窄/矮屏底部 292×62 横条，五入口；A 还含左上双圆天气、纪念卡、音乐与头顶状态。旧 Discord 通栏侧栏已删；2026-08-10 的「全尺寸底部胶囊、45s 淡出至 12%、全隐藏」是未完成历史提案，不作基线。

**当前契约**：A 不开全屏暗幕；B 覆盖 A 并限制后台交互；菜单跟随宿主；Esc 一次关一层、关闭归还焦点；保存失败保留输入，成功反馈必须对应真实结果。规格与响应式矩阵见 Feature §4、§7。

**天气菜单滚动**：外壳与反光边不承担滚动；仅内衬内容超高时出现细条纵向滚动，禁止横向滚动。正常容纳全部选项时不显示滚动条。

**回忆页**（2026-10-01 起是内容页，模态）：桌面正中一个大窗，房间压暗虚化；手机直接全屏，从底边升起，没有半开，页头有关闭按钮，也能下拉关闭。两个标题页签（日记 / 照片墙），页头的小开关换「样子」：日记 手帐 / 日历 / 书本，照片墙 拍立得 / 软木板 / 相册 / 放映，选择会记住。灯箱是更上一层的模态，Esc 先关灯箱、再收写一页、再关目录、最后关页；关掉再开，草稿、滚动和页签都还在，草稿换样子也不丢。详细流程见 [UX 参考 §4](cinnaglass/ux/ux.md)。

**所有 B 已实施的交互**（2026-09-20）：原生 `showModal()` 进入顶层，背景不可点/不可 Tab；聚焦标题，Esc/点外/关闭按钮收起后回到入口。正文滚动，折叠密码区使用 `hidden`；外观即时生效，密码关闭重开保留本次草稿，昵称保存失败保留输入可重试。改密/退出仍使用真实账号链路。照片光箱和编辑/表情层先消费 Esc，不连关父窗；确认弹层卸载也返回原触发位置。

## 4. 聊天体系

- **世界内（当前）**：消息以对方角色头顶短气泡呈现，贴纸用文字提示；表情/贴纸驱动角色动作是未来提案，未接入角色系统。对坐书房（开发环境）里气泡改到对方脸侧、名牌落在肩线，手机贴右边缘，规则见 [UI 地图](uiux.md#对方身边的气泡与名牌)。
- **UI 层**：窄窗可展开到 ChannelScreen，旧「绝不做大窗」与实现不符。目标是 A 负责边看场景边聊、B 负责完整历史与复杂操作；去掉服务器式壳层，不删编辑/删除/重试/reaction/贴纸能力，文字区要稳定可读。
- **长椅仪式（招牌场景，Sky 聊天长椅原型，未实现）**：双方在线且空闲时两只小狗同坐沙发 → 「对话模式」：聊天 dock 升起、环境音渐弱、灯光聚向沙发。雨天+长椅+共听音乐是名场面；MVP 后先做气泡+dock。

### 当前浮窗、草稿与真实状态

- 导航「聊天」「一起听」是开关：关闭时点开，打开时再点收起，选中高光与 `aria-expanded` 跟随真实状态。音乐收起保留迷你条与播放；组件已隐藏时从导航恢复并展开。唱片机入口遵循同一开关规则，窄/矮屏互斥仅在打开另一浮窗时执行。
- **手机托盘（2026-09-29 实现，09-30 看样保留，10-01 改）**：窄于 768px 或矮于 600px 时，聊天、音乐、房间、回忆入口都从底边升起一个托盘，盖住我这边的手和杯子，半高停在对方书下，对方的脸和上身完整可见；竖屏时**导航并进托盘当它的脚**（同一块玻璃，不再单独浮着一块胶囊）；每个托盘头有**关闭按钮**，点当前图标、往下甩、Esc 也能收起并把焦点还给入口；托盘从任何地方都能拖、跟手，放手按推算的落点停下（§6）。**同一时间只开一个窗口**：开托盘、内容页、任务窗或时辰 / 天气面板时，开着的那个自己收起。音乐托盘可拉到全高看歌词和歌单，其余按内容高度。托盘非模态：场景仍可戳、可摸头。手机上没有悬浮音乐条，出声时导航音乐图标带小音柱；房间里不再显示「音乐迷你条」开关。竖屏手机上的 B 任务窗同样从底边升起；日记和照片墙是内容页，直接全屏。实现 [sheet.tsx](../../../src/themes/cinnaglass/ui/sheet.tsx)，比稿 [ui-motion](../codex-visual/ui-motion/ui-motion.md)。

- 桌面聊天左下、音乐右下，左上天气/右上纪念卡分开；窄于 768px 或矮于 600px 使用底导航布局，展开聊天与音乐互斥，纪念卡避让。关闭音乐面板不暂停音频；隐藏 widget 保留播放引擎。
- 「时辰 / 天气」采用左上双圆：时钟/云表示类别，角标表示状态，名称在 hover/键盘焦点时出现。点击展开，再点关闭，两菜单互斥；点击、横拖或方向键选择。Esc 回到触发钮，点外/Tab 离开关闭且不抢新焦点。展开状态只显示必要短词：定位中、实况不可用或实际天气温度；手动模式不伪造地点温度。较矮桌面向右展开，避免遮住竖导航。
- 新来信使用金亮信纸：对方有效未读消息触发，自己的新消息不覆盖未读提示；仅阅读当前世界会话才收起提示，其他会话不清掉它。点击进入聊天后沿现有已读流程更新，失败仍保留未读，删除消息不提示。信纸不另建通知或已读存储；收起聊天时焦点返回聊天导航。
- 信纸出现时桌面纪念卡向下避让、小屏隐藏纪念卡；宽度 ≤1100px 或高度 ≤700px 展开播放器时提示卡暂时让位，未读点仍可见，收起播放器后信纸恢复。
- 聊天输入法确认不发送。聊天展开关闭返回原入口；切换会话依旧清除未发送草稿，失败发送留在消息列表供重试。好友与贴纸删除使用内联确认，搜索 Enter 不提交聊天表单。
- 设置昵称失焦/Enter 保存，失败留稿；密码关闭重开保留本次挂载草稿。头像注明仅本机保存，操作可键盘触发，调整态 Esc 先完成调整。世界设置取消后恢复已保存值；日历关闭保留当前组件草稿。照片光箱 Esc 只关光箱。
- 纪念日来自世界资料，无日期时不虚构纪念日。姓名不是在线指示；本机心愿/约会/提醒明确存储范围，提醒不发通知；音乐为本机 WebAudio 音景，不代表共享听歌。
- 「减少透明效果」即时生效并保存偏好；旧卡片配色不再提供无效开关，旧存储只留给兼容消费者。此偏好不改日记。

### 手机输入与布局

窄于 768px 或矮于 600px 使用紧凑布局并避开安全区；完整聊天会话列表按需展开，选择后收起，Esc 分层关闭。触屏打开窄聊天/音乐不自动聚焦输入；桌面保留焦点便利。横屏完整播放器隐藏重复迷你条，通过导航收起。

软键盘出现后按可见视口收紧 A/B 窗口，暂时让导航和环境控制退场，关闭键盘恢复；旋转不重建会话，不丢当前草稿。允许双指缩放且不将其误判为键盘。具体图片、来源与真机边界见 [手机版规范](mobile.md)。

## 6. 动效：全局体系与低动效模式

2026-09-29 用户要求把动效做起来（游戏 app，任何交互都尽量有反馈，不必太克制，因为有低动效模式）。按推荐方案实现，**2026-09-30 用户看样后保留**；方案与调研在 [UI 动效与手机托盘](../codex-visual/ui-motion/ui-motion.md)，每种交互的流程与录屏在 [UX 参考](cinnaglass/ux/ux.md)。

- **一套 token**：`--ease-out` / `--ease-in-out` 取自 Emil Kowalski 的技能。**弹簧按苹果的模型**（2026-10-02 用户要求参考苹果的弹簧曲线；WWDC23「Animate with springs」）：一根弹簧只由「感觉多长」和「回弹多少」两个数定，质量 1、刚度 (2π / duration)²、阻尼比 1 − bounce；CSS 曲线是这些弹簧采样出的 `linear()`，时长取弹簧真正停稳的时刻，由 [spring-curves.mjs](../../../scripts/spring-curves.mjs) 生成。四根：`--spring-smooth`（0.42s · 0，621ms，托盘与内容页升起）、`--spring-snappy`（0.36s · 0.15，504ms，面板与卡片）、`--spring-bouncy`（0.42s · 0.3，692ms，回弹 4.6%，标签滑块、视图切换）、`--spring-pop`（0.34s · 0.42，667ms，回弹 10.7%，放开按钮、开关圆钮、小红点）。按下 90、悬停 160、进场 260、退场 150、托盘收起 280（ms）。唯一真源 [motion.css](../../../src/themes/cinnaglass/ui/motion.css) 与 [spring.ts](../../../src/themes/cinnaglass/ui/spring.ts)，各组件样式只引用。
- **拖动**（WWDC18「Designing Fluid Interfaces」）：移动 6px 才算拖，之前按下还是按下；之后 1:1 跟手；过了边缘用 iOS 滚动视图的橡皮筋（系数 0.55）；放手按减速率 0.998 推算落点，停在离落点最近的位置，弹簧从手指的速度起步（release 0.38s · 0.12；快于 0.5 px/ms 的 fling 0.34s · 0.22；收起用 away 0.32s · 0，不弹回来）；半路再按住会停在手指下。托盘和手机内容页的下拉都按这一套。
- **规则**：按下即时缩小、放开回弹（0.95，大块 0.97）；悬停只在鼠标设备上浮；弹层从触发点长出、退场快于进场；不从 `scale(0)` 出现；只动 transform / opacity；列表逐项错开 28–40ms；循环只给真实在进行的事（播放中的唱片与音柱、等待中的热气与转圈）。
- **低动效模式**：设置 → 主题外观 → 动效「跟随系统 / 完整动效 / 低动效」，结果写在 `html[data-motion]`（[motion-preference.ts](../../../src/themes/cinnaglass/ui/motion-preference.ts)）。低动效把位移、缩放、回弹归零并缩短时长，保留淡入淡出与颜色、光晕变化；循环与粒子关闭；房间的视差、微动与蒸汽停下（下次进房间生效）。回忆面板同样跟随这三档；旧棕皮书只跟随系统设置。
- **环境圆钮**：用户已批准的 360ms 选中透镜滑动和 180ms 展开保持原参数，低动效时关闭。**旧「果冻时长表」已作废**，原参数留在 git 历史（3fd52a5 的本文件 §6）。

普通转场不超 500ms；弹簧的时长是停稳的时刻，感觉上的时长都在 0.42s 以内（回忆面板的新页落下 620ms、沉浸歌词底图 900ms 是有意的庆祝与氛围，低动效下都改淡入）。**另一个例外**是旧棕皮书的实体翻书（2026-09-07 接入三维竖直翻页，现为「书本（旧版）」）：时值、连翻队列、加载与页码真实性、「减少动态效果」行为见 [turn-implementation.md](cinnaglass/journal-room-object/turn-implementation.md)，本页不复制参数；拿起/收回与羽毛笔交互仍待办。

## 7. 音效体系：水滴系（与雨 ASMR 同一材质宇宙；提案，src 中尚无音效实现）

- **水滴 = 确认**、**涟漪 = 切换/翻页**、**湿润 soft pop = 点击**（300–600Hz 圆润起音、无锐利 attack、极少混响）
- 动森法则：音效时值与动效时值对齐（150–250ms）；同一动作永远同一声音；连续点击做音高阶梯（+2 半音递进）
- 全局音效音量随 ASMR 音景独立可调、可全关
- 候选资源：BOOM CASUAL UI（商业）、shmyak ui paper（纸质，贴水彩）、Kenney Interface Sounds（CC0 起步）

## 8. 质感与使用方式

2026-09-11 的范围是三类载体与共享控件，不再把「玻璃/纸/木/果冻」当作每个界面必备的配方：

- A 用导航同源细纹磨砂；B 已采用连续厚磨砂壳与随时辰内衬；C 按物件决定。
- 纸只用于获准的内容本身，不把设置/日历整窗画成旧纸；照片内容保留纸框。日记 2026-09-07 已迁到棕皮旧纸、覆盖 B 的灰苔封皮（材质与阅读/草稿规则见 [C 专属物件 UI](cinnaglass/ui-system.md#c-专属物件-ui)），通用表单已用受色阅读内衬。
- 木、皮革、手写字体留给真正的物件与内容；A/B 控件默认清晰无衬线字体。
- 暖金用于操作反馈，蓝/粉用于身份，绿/红用于真实状态；不能用在线绿点作装饰。尺寸与状态见统一计划，本页不复制第二份 token 表。
