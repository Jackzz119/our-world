# A「对坐」姿势与时天气候扩展 · 视觉交付

## 1. 模式与规范化 brief

- **模式：design。** 交付 1 张九宫格姿势板及 11 张房间时辰 / 天气变体，共 **12 张最终 PNG，均 1672 × 941**，约 16:9；另保留 5 张被单独修正的初稿。
- 产品是情侣 / 亲友共同使用的陪伴空间；镜头就是坐在桌前的真人用户，对面角色代表另一名真人。该批是概念设计，未接入产品。
- 核心验收：每个场景只有一名对坐伙伴；桌后半身；观者双手与袖口可见；小满在对面时前景炭灰卫衣袖，阿屿在对面时前景米白针织袖；全组禁止托腮。趴桌格按 brief 使用侧脸贴平放前臂。
- A1 锁定小满与家庭房间，A5 只锁定阿屿身份 / 画风，不复制头像编辑器 UI；每张房间图另传对应首轮 keyart，保留主要建筑、桌面与标志物。
- 高级 2D 动漫 CG：细线、柔和赛璐璐与绘画渐变、暖肤色、发丝和衣料细节、实用灯与环境光对比、前中后景层次。无光圈、交互描边、pin、角色复制倒影。
- 场景不加标题、UI 或说明文字；姿势板仅用“姿势库”与九个短标签。书报与写卡动作中的不可读物理纹理有单列边界，见第 6 节。
- 制作使用**内置 image_gen**，一图一次调用，局部失败才单图修正；无 CLI / API-key 回退。所有交付及过程证据都在本目录，参考文件未被覆盖。

## 3. 执行结论

**这组图已经把“托腮拿杯”的单一默认姿态展开成可辨识的生活动作，并证明同一房间可以通过天气、光照、衣装与动作产生不同片刻。** 看书、侧望、键入、抬臂、趴桌、遮嘴笑、喝水、画画、抱枕，以及护苗、浇水、坐睡、扶发、指星、写卡、撑伞、吹茶、选照片，主体轮廓与视线都有区别。

推荐优先以**姿势板 + 咖啡馆早晚**作为动作制作样板：人物、桌面接触与光差清楚，室内结构稳定。温室护苗 / 浇水、海边指星、暗房选片提供下一组更明确的共同仪式。

验收包含制作者自审、主代理逐张开图复核，以及非制作 agent 对姿势 / 咖啡馆、温室 / 书房、天台 / 木屋 / 暗房的交叉复核。海边 / 列车由制作 agent 自审后，主代理独立打开检查。**这不是委派方 Monet 的最终定稿批准。**

5 张明确问题已经修正并保留初稿：姿势板抬手裁切、暗房安全灯错误开启、列车伪印刷字、书房伪手写与书脊字、夜温室水流与扶壶接触。没有整批重跑。

## 5. 逐图观察、用途与制作建议

以下“观察”来自实际图像；“拆层 / 动画 / 玩法 / 预算”均为提案，未实现或压缩实测。MB 均为粗略传输体积估计，不等于 GPU 显存。

### 01 · VA-poses.png

![姿势库](../img/VA-poses.jpg)

**观察与用途：** 3 × 3，标题“姿势库”；九标签为看书、望向窗外、打字、伸懒腰、趴桌、捂嘴笑、喝一口、画画、发呆。九格都见左灯、雨城窗、右唱机与前景炭灰袖。读书低眼、侧望轮廓、屏前双臂、上举双手、贴臂侧脸、捂嘴、杯沿上目光、执笔、抱枕有可读差异。伸懒腰修正后双手完整在格内。

**弱点：** 单格约 550 × 270 像素，不足以作为最终手指部件。打字有一手被屏幕遮住；侧望格更像望向侧后方。不同姿态面部角度和局部尺度存在轻微变化，不是可直接接成逐帧动画的注册序列。

**制作：** 复用同一空房背景、身体基座、发片、眼嘴；书 / 笔 / 笔记本 / 杯 / 靠枕独立。小动作可共 rig；举臂、侧身、趴桌需要替换肩臂与头颈姿态，不强拉同一网格。前景双手另成 rig。板图压缩预览估计 0.45–0.9 MB；一套角色基础图集约 2–4 MB，九姿态增量约 1.5–3 MB，须实际拆层验证。

### 02 · VA-cafe-morning.png

![咖啡馆晴晨](../img/VA-cafe-morning.jpg)

**观察与用途：** 圆大理石桌、左花与烛杯、右草莓蛋糕、右皮卡座、蓝电车与铜吊灯保留。窗外干燥明亮，低阳光照桌，阿屿换浅衬衫与毛衣，双手展开报纸，从上缘抬眼。前景米白袖捧杯，蒸汽在光中可见。它把眼神交流写成“看报间隙的抬头”。

**弱点：** 报纸遮住大部分躯干，后续动作幅度要小；纸面是不可读排版纹理。晨灯仍明显，后续灯层可减弱以突出阳光。

**制作：** 临街背景 / 窗框 / 室内 / 桌 / 花与蛋糕 / 角色 / 报纸 / 前景手杯分层；眼球抬眼、纸角小弯折、蒸汽独立，手指约束报纸边。压缩静帧约 0.35–0.75 MB；含背景、共用人物与道具的首次房间估计 3.5–6.5 MB。

**玩法（5 步提案）：** 选定晨间共读 → 观者在报纸夹一枚图形书签 → 对方端同页出现纸签翻角 → 真人点开 / 回夹另一枚纸签 → 自愿收藏当天共读片刻。离线时留下纸签，不触发假的抬眼。

### 03 · VA-cafe-night.png

![咖啡馆打烊前](../img/VA-cafe-night.jpg)

**观察与用途：** 后方椅子倒置上桌，唯一室内亮吊灯照着本桌，烛杯熄灭。阿屿一手捏硬币、一手扶纸袋，空罐与币堆在桌上；前景米白袖捧杯。窗外湿街与霓虹、蓝电车保留，使共同收尾成为独立动作。

**弱点：** 表情温和但疲倦感不强；中央窗外出现蓝紫高楼，与首轮临街远景有漂移。玻璃仍有水珠，只能看出雨后湿润，静帧无法证明雨是否已完全停止。室内关键布局延续，不能宣称外景逐像素一致。

**制作：** 吊灯光区、街面反光与室内静态底分开；罐 / 硬币 / 纸袋 / 左右手独立，捏币至袋口是一个完整短动作，袋口有遮挡层。静帧约 0.35–0.7 MB；复用咖啡馆底包后，夜景与道具 / 动作增量估计 1–2.2 MB。

**玩法：** 打烊收拾触发 → 观者把桌上零钱拨成小堆 → 对方端袋口收到同一组硬币与轻响 → 真人收拢纸袋并放在两杯之间 → 收藏一次共同收尾。无金额目标、排行榜或迟到惩罚；异步留下待收袋。

### 04 · VA-greenhouse-rain.png

![温室雨天](../img/VA-greenhouse-rain.jpg)

**观察与用途：** 白玻璃框、悬蕨与工具位延续；窗顶和玻璃水痕明确，色调转灰绿。小满将小盆托到胸前，另一手在幼苗上方挡护，手与下巴有间隙。桌上保留另一只盆与标本册，原中文姓名挂牌移除。动作使植物成为两人共同照料的对象。

**弱点：** 发丝和脸仍有较强暖光，阴雨氛围主要由背景承担；地面雨声不能由静帧证明。

**制作：** 窗外雨 / 玻璃雨珠 / 室内叶片分离；盆、苗、托盆手、护苗手独立，盆和苗共坐标。雨滴不得跑进人物层。静帧约 0.45–0.9 MB；初次房间含共用角色估计 3.8–7 MB。

**玩法：** 窗顶开始落雨 → 观者把小盆拖到桌内干燥位置 → 对方端出现对应护苗结果与叶尖水珠 → 双方选择一片标本叶留在册中 → 自愿记录雨日生长。植物不会因未操作死亡；离线也保留照料结果。

### 05 · VA-greenhouse-night.png

![温室星夜](../img/VA-greenhouse-night.jpg)

**观察与用途：** 同一温室增加绕植物的串灯，蓝夜空露星，浅色夜花与铜壶有暖光。小满张嘴笑，一手提小壶，一手托壶底；修正后细水流只从壶嘴落入左苗盆。前景炭灰袖和标本册不变。浇水提供清楚的手部任务。

**弱点：** 灯点与花瓣密，长驻小窗口容易显得热闹；大量微闪不应直接照搬为动画。

**制作：** 串灯静态发光为主，仅少量亮度变化；小壶 / 上握手 / 托底手 / 单水流 / 土表反应独立，水流端点绑定盆内。夜花张合宜缓慢。静帧约 0.45–0.9 MB；复用温室后的夜景 / 浇水姿态增量约 1.3–2.8 MB。

**玩法：** 真人选择晚间浇水 → 观者倾斜小壶给一只盆加水 → 对方盆面出现同样涟漪与柔亮新叶 → 对方实际回应后两盆并排多一片叶 → 自愿把叶形压入标本册。没有连续签到或浇水过期惩罚。

### 06 · VA-study-dawn.png

![书房黎明](../img/VA-study-dawn.jpg)

**观察与用途：** 左绿灯 / 星罐、右电脑 / 沙漏、窗格 / 雪松 / 远塔保留。蓝晨光取代月夜；阿屿闭眼坐着，眼镜推至额头，毯子只盖一肩与手臂，双手落在桌上。修正后两本摊开的本子无字，书脊保留皮革和金线，银行灯减亮。姿态打破所有图片都对视的惯性。

**弱点：** 单肩毯静帧只能表示披挂状态，不能证明正在滑落；本子清空后，通宵工作线索主要来自电脑、笔和堆书。主体暖肤色仍强于真实冷清晨，是画风取舍。

**制作：** 窗景 / 室内灯光分层；闭眼脸、额头眼镜、偏头颈、披毯、静置手 / 笔独立；仅极轻呼吸，不能用随机睡姿暗示真实人已睡。静帧约 0.35–0.7 MB；房间首次资源估计 3.5–6.5 MB。

**玩法：** 对方本人明确选择睡眠状态 → 观者把毯角轻轻拉好 → 对方端留下毯子与待看纸签 → 本人回来取消睡眠后阅读纸签 → 可选保存一句晨间留言。普通断线 / 离线必须空椅留痕，不得自动生成坐睡的人。

### 07 · VA-seaside-storm.png

![海边暴风雨前](../img/VA-seaside-storm.jpg)

**观察与用途：** 白木桌、左风铃与帘、右百叶 / 草帽、早餐道具保留；深云盖住海，地平线一条金光，近岸有浪。小满一手压住扬起的头发，另一手稳杯，笑容兴奋；炭灰袖观者仍坐在前方。

**弱点：** 风铃静态摆幅较小；脸与桌面金光较强，风暴压力被有意减弱。桌面尚未收拾，是暴风前的瞬间。

**制作：** 云、金光、海面、近浪分层；帘网格、逐串风铃、头发用同一低幅风参数；扶发手与发片不穿插。静帧约 0.45–0.9 MB；含角色的初次海边房间估计 3.7–7.6 MB。

**玩法：** 阵风使风铃轻响 → 观者拢帘 / 扶稳风铃 → 两端帘和铃摆幅同步减小 → 对方桌边留一枚选好的贝壳 → 自愿收藏一次海风片刻。离线只留下贝壳与空座，不能伪装对方即时笑容。

### 08 · VA-seaside-stars.png

![海边星夜](../img/VA-seaside-stars.jpg)

**观察与用途：** 保持白木露台，桌上一盏铜灯笼，银河和星光铺满海天，近岸蓝荧光。小满抬臂指星，眼睛跟随指向，另一手持杯。金星夹可见于右耳上方约 (1123, 204)，身份配件未丢。共同看外部世界使陪伴不依赖持续凝视镜头。

**弱点：** 星点很密，暖脸 / 毛衣偏亮；夜晚仍沿用吐司、鸡蛋和果汁，体现保持原道具的约束，但叙事略违和。竖屏中裁会切掉指尖。

**制作：** 银河静态纹理、少量低频星闪、岸浪荧光、灯笼火与光区各自独立；抬臂使用替换姿态和指手，配合眼球偏转。静帧约 0.5–1 MB；复用海边后的夜间增量估计 1.4–3.1 MB。

**玩法：** 看见一组星点 → 观者在空白小卡点出星位 → 天空回应短暂细星闪 → 对方桌边得到同一张星图卡 → 自愿收入共同夜空册。提示不是光圈；对方离线时仅留下卡片。

### 09 · VA-train-dawn.png

![列车海岸清晨](../img/VA-train-dawn.jpg)

**观察与用途：** 左大窗与流苏灯、红绒卡座、右纵深走道、便当 / 银杯托 / 印章 / 皮册 / 地图保留。窗外日出海岸与横向掠影区分于原雪夜。小满低头，一手握笔，一手压明信片，炭灰袖观者看路线。已修掉首稿明显伪印刷字。

**弱点：** 卡片仍留一条极细写作笔迹，没有可读句子；不能称为像素级零笔迹。室内灯较亮，日出主要由窗外承担。单张无法证明列车持续行驶。

**制作：** 窗外天 / 海 / 远岸 / 近树分速横移并遮罩于窗内；车厢固定，笔尖、写字手、压纸手、卡片分层。静帧约 0.45–0.9 MB；首次房间含角色估计 3.9–7.7 MB。

**玩法：** 海岸景观经过窗外 → 观者选风景卡并按木印章 → 对方端卡片出现图形章，由真人填写内容 → 卡片进入双方桌侧皮册 → 自愿收录这一程。异步卡可留存，未在线者不显示自动代写。

### 10 · VA-rooftop-rain.png

![天台夏雨](../img/VA-rooftop-rain.jpg)

**观察与用途：** 河岸城景 / 串灯 / 望远镜、左灯笼与西瓜、右音箱延续。透明大伞骨架与水珠横跨上沿，右侧伞杆固定座清楚，阿屿一手握杆、另一手放桌上开口笑；米白袖前景在同一伞下。

**弱点：** 是偏暮色的夏雨，城市灯仍多；雨雾浓度适中而非完全模糊。伞减少天空面积；单裁切无法证明后方全部设备都被伞覆盖。

**制作：** 伞骨、透明伞面、杆 / 夹座、水珠各拆层；握杆手跟随约束，雨限伞外；灯珠滴水和环境雨分开。静帧约 0.35–0.75 MB；首次房间估计 3.6–6 MB。

**玩法：** 阵雨落下 → 观者轻敲杯缘留下一段节奏 → 对方端同一杯出现对应轻响 → 真人各添一段雨天合奏 → 自愿保存声片。异步回放只作用于物件，不模拟真人正在笑。

### 11 · VA-cabin-day.png

![木屋雪后晴天](../img/VA-cabin-day.jpg)

**观察与用途：** 左石壁炉、右雪窗 / 唱机 / 沙发、桌上棉花糖与棋盘盒不变。窗外蓝天、雪林与清晰山体，炉火比原图小得多。阿屿穿厚灰绞花毛衣，双手捧杯到唇边、轻噘嘴吹茶，前景米白袖捧同款杯。

**弱点：** 披毯仍留在双肩，动作轮廓变化小于其他房间；前景蒸汽强于伙伴杯蒸汽。外景远山因晴天更清楚，不是相同底图直接滤镜。

**制作：** 雪窗 / 室内 / 低火 / 灯光分层；毛衣、披毯、头嘴、双手、杯、蒸汽独立，手杯成约束组，吹气只轻改蒸汽方向。静帧约 0.4–0.8 MB；首次房间估计 3.7–6 MB。

**玩法：** 真人选择泡茶休息 → 观者选茶包、倒水、轻吹 → 对方杯中出现对应茶色与蒸汽 → 对方实际举杯确认留下成对杯垫痕 → 自愿收藏茶配方。离线可留待泡配方，没有变冷倒计时惩罚。

### 12 · VA-darkroom-lights.png

![暗房开灯整理](../img/VA-darkroom-lights.jpg)

**观察与用途：** 左放大机、红罩安全灯、后晾片绳、右蓝门边 / 收音机、前景三盘对应原房间。安全灯内部为暗色，普通白暖工作照明替代红光。小满双手分别举海景和白花照片，胸前并排不遮脸；炭灰袖观者用食指选择，开放相册成为动作结果的归处。

**弱点：** 普通顶灯本体在画外，只能由照明效果确认；相册加入导致前景显影盘稍前移。相册应处于干燥台面区，生产分层要强化与湿盘的边界。

**制作：** 关灯灯具与常规照明遮罩分离；两张照片为独立平面，绑定各自手指；相册页 / 卡片 / 翻页遮挡 / 前景指选手独立。静帧约 0.3–0.65 MB；首次房间估计 3.5–6 MB，不含用户照片下载。

**玩法：** 两张干照片待选 → 观者指选并拖向相册空位 → 对方端看到同一候选与页位 → 真人确认或换图后相册同步翻页 → 该页成为共享回忆。离线保存候选夹，不替人做选择。

## 6. 不确定性、可比性与剩余问题

1. **空间连续性是视觉锚点连续，尚非注册式重光照。** 摄像机总体一致，但外景纹理、盆位置、相册前的托盘和部分手持道具有变化。不可直接把两张交叉淡化当成最终生产光照方案，否则可能“融化”或抖动。夜咖啡馆的高楼是最明显的外景漂移。
2. **姿势板和场景图任务不同。** 板内单格较小，不能与整张场景比手部细节或皮肤完成度；侧脸 / 抬臂 / 睡姿的脸型也不能按正面像素重叠判身份。
3. **无 UI / 标题与零物理笔迹有区别。** 11 张场景没有叠加标签、字幕、操作 UI；晨报保留抽象排版纹理，列车保留正在写卡的一条细笔迹，远景灯牌是不可读光斑。若验收要求所有类文字纹理都归零，这两张仍需再清理；本报告不把它们说成像素级绝对无字。
4. **天气动态和真人状态无法由静帧证实。** 星闪、伞晃、雨声、杯汽、翻页均是建议。闭眼睡姿只绑定本人主动设定的状态；其余情绪 / 动作也不能随机伪装成真人反应。
5. **本批是合成 PNG，尚无透明部件、PSD、rig、模型或代码。** 压缩预算没有实测，移动端竖裁也未验收。两张大抬臂动作尤其需要竖屏重排。
6. **光照仍有风格化取舍。** 温室雨天暖高光、海边星夜亮脸与密星、列车晨灯偏亮，是已观察到的轻微问题。长期常驻时应压低背景微闪频率和密度。
7. **原道具保持与时间叙事存在冲突。** 海边夜景仍有早餐，咖啡馆打烊仍有完整蛋糕；本轮按用户的原布局 / 道具保持要求交付，下一步可另设计道具状态，不把所有物件强行跨时段冻结。

## 7. 推荐与后续制作

- 先选姿势板中的读书 / 画画 / 喝一口做同一半身 rig 样板，再单独攻克举臂 / 侧身 / 趴桌。先保证手与道具接触，不以整图缩放代替动作。
- 咖啡馆早晚作为同房间光变样板：从一个确定几何的空房拆背景、桌面、角色与光层；修正夜图的外景漂移后再做过渡。
- 温室与暗房优先验证一个真实可操作循环：观者触发 → 物件反馈 → 对方实际操作 / 异步留存 → 共享结果。当前图已经给出可见的壶、苗、照片、相册关系。
- 天台雨、海边星夜保留为环境表现样板，减小自动变化；木屋与书房做安静状态样板。
- 这些是生产建议，不是本轮缺失交付。委派方 Monet 负责最终选择与常驻设计系统晋升；本轮没有发布、上线或替换正式资产。
