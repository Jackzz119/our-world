## 铁律（用户定规）

- **2026-09-06：部件必须由生成产出，不后抠、不手修。**
- **2026-09-07：死物吃画里的光，活物吃场景的光。** 静物保留原画光影；会动的件出平光固有色，光由引擎给。
- **状态 = 参数缓动，永不换图。** hover 只改 tint / 速度 / alpha；换图与描边高亮路线用户已逐轮否决并删除。

## 路线结论

主力路线唯一：**物件拆层 + 引擎内程序动画**（transform / alpha 缓动），辅以粒子与 ≤2 个着色器区域；有机形变（蒸汽 / 窗帘 / 猫尾）用 8-16 帧手绘循环或网格扰动兜底。这就是 Wallpaper Engine 数万张「静图活化」壁纸的工业标准做法（Spin / Swing / Glitter / Water Ripple 全是遮罩圈区域 + 便宜效果）。**Spine（mesh 需 Pro $369）/ Live2D（Pixi v8 无官方支持）/ alpha 视频（Safari 双编码坑）对本需求都是非必要重武器。**

标杆：lofi girl 是 TVPaint 逐帧离线视频，不是实时技术参照——它证明的是**动画密度阈值**：2-3 个主循环 + 几处微动，场景就「活」，所以第一期只做唱片机 + 许愿罐。Rusty Lake 的机关粒度（一物件 2-4 可动层 + 触发式短动画）与 hover 需求最接近；Spirit City 是 UE5 全 3D，与水彩底图不兼容。

| 需求                    | 拆层                                                       | 动效                                                                                                                   |

## 唱片机实装（v5，2026-09-07）

### 透视旋转

底图的透视椭圆**直接旋转必穿帮**。量测用 `scripts/fit-disc-ellipse.py`：外沿按 137 个边缘样本做最小二乘椭圆（rms 0.5px），标签椭圆定真实圆心（在外沿圆心上方 3.8px，是原画的真实透视而非画错）；三档构图在 ±0.5px 内一致，一份 spec 通吃。`pixi-scene.ts` 的 `discHomography()` 由「外沿椭圆 + 真实圆心」解出单应矩阵（圆保持映射 + Klein 模型双曲平移），`discCorners()` 供 `PerspectiveMesh` 取角点——**只剩旋转角一个自由度，圆心与外沿转动时都不漂**；纯仿射压扁再转做不到两者同时不动。

### 分层原则与产物

- **机器（死物）**：codex 生成「无唱片、无唱臂、空盘槽 + 转轴针」三档图，只在盘位 + 唱臂脚印的羽化区贴回原画（脚印外零差，接缝环差 0.8–1.0/255）；**单一 donor（twilight）几何 + 逐档颜色仿射匹配**，保证切时辰不变形。
- **唱片（活物，按旋转对称性分解）**：黑胶的「质感」本身就是光打在沟槽上，固有色近乎均匀黑——所以不按「去光」拆，按**转起来看不看得出**拆。外观基底 = 原画盘面每半径的角向中值（旋转对称部分）+ codex 标签印花贴花（月亮 / 笔触，按原画标签逐环着色），归一到内接单位圆 512²。
- **光层（永不随盘转）**：原画 − 对称部分，逐像素不模糊，正值走 **add**、负值走 **multiply**；唱臂与针的遮挡区沿圆环角向插值补洞。三档各自分解、各自一套，**不再有 `platterTint`**。
- **唱臂**：codex 平光固有色零件，按金色档校准，逐档 `armTint` 给光比（`#ffffff` / `#808bc0` / `#78828a`）。
- **转轴针**：死物，从各档原画按多边形羽化直接切出（`spindle-<mood>.png`），不用生成件。
- 装配器 `scripts/build-turntable-parts.py`（Pillow / numpy / opencv），产物 `public/rooms/study/parts/` + `turntable.json`；原画真源 `arts/rooms/study/source/`，生成图层归档 `arts/rooms/study/generated/`。几何数值在 `study-room.ts`，全部粘自 manifest，不靠目测。

### 运行时

512² 母图按实际显示尺寸逐级折半重采样后 1:1 采样（关掉 mipmap 级间插值）。转速 idle 9s/圈，hover 软坡到 4s/圈（×2.25）。唱臂 hover 由欠阻尼弹簧状态量 `lift` 驱动（k=120、damp=14，约 0.3s 内响应、一次轻微过冲）：**绕转轴柱的垂直剪切** 0.045rad（柱不动，约 90px 外的唱头抬起 ~4px）+ 0.012rad 外倾；投影由零件 alpha 运行时烘出，按 mood 光向 `armShadow` 偏移，抬起时滑开 1.6×/1.8× 并淡 40%。mood 交叉淡化走 holder、`lift` 走 sprite，两条 alpha 不打架。

### 闸门数值

- 静止复原（基底 × 光层 + 针）vs 原画，盘内、唱臂外：**mean 2.2–2.5/255、p95 6.4–8.2**。
- 补丁区外底图逐位相同；接缝环差、配准偏移与审阅条由装配器输出。
- 浏览器三档 + hover 抬针实测正常、无报错。

### 教训

- **codex / gpt-image 局部重绘不合格**（残影、接缝、不锁像素）：生成图只能当「捐体」贴脚印，不能当就地修图。
- **颜色阈值抠件必穿帮**：「多边形 ∪ 暗色像素」会把投影和盘边一起抠进零件，一摆动就露馅——抠件要按形状，最终改为生成优先。
- **光层里不能带原画的径向纹路**：与生成标签的半径不一致会叠出双边发糊。
- **生成部件的几何按一档统一再配色**，否则切时辰变形。
- 贴图尺寸先贴近显示尺寸，再谈 mipmap。
- 第四轮「去光留质感」方向自相矛盾（生成固有色标签亮 47%、半径偏大、黑胶偏冷、光层被 σ=8 抹平、机械同心圈缩成摩尔纹），第五轮改按对称性分解才成立。

### 历轮结论（一行制，日期与范围见 [TODO](../../TODO.md)）

一轮：透视真旋转 + 宽幅高光拆静态加色层｜二轮：手描剪影真分件 + clean plate（闸门 mean 0.2–0.5/255）｜三轮：生成优先、绿幕键出 + 参数化投影｜四轮：完全分离 + 固有色 / 光分层｜五轮：唱片按旋转对称性分解，盘面与转轴针回到原画级。

## 分层资产 AI 管线（七步）

原型是 WE 的 Puppet Warp 官方资产流程：抠件 → 底图补洞（不完美没关系，动画件盖住）→ 罩动效。

0. **运动设计清单先行**——切割线由运动决定（盘 vs 臂），不由物体轮廓决定。
1. 抠件：全画布尺寸导出（保留文档坐标系），每物件一文件夹。
2. 底图补洞（clean plate）：局部 inpaint 带全图上下文修，修完 diff 校验只有洞区变了。
3. 零件补全：被遮挡部分补全整件（旋转件必须补成完整圆）。
4. **差分校验闸门**：clean plate + 全零件原位叠回 ≡ 原底图（洞区除外）。
5. 打包：trim + offset / pivot / z 记入 manifest。
6. 有机件三级火箭：引擎程序化优先（粒子 / MeshPlane 扰动）→ AI 图生视频循环（**首尾同帧直出循环不可靠，用两段拼接法**）→ 烘 8-16 帧 sprite sheet（≤256²）；大件才考虑 alpha 视频（VP9 + HEVC 双编码）。**AI 视频拆帧不能当主力**——水彩会沸腾。
7. **hover 差分不出图**：亮度 / 速度全在引擎内做（tint / additive / 参数）。

## 性能预算（30fps 上限 + 失焦暂停红线下）

- 动态 sprite ~40 层 + ≤50 粒子对 Pixi v8 是零头（基准 20 万 sprite@60fps）。
- 真预算在：纹理内存（帧动画 256²×16≈4MB/件，有机件 ≤3-4 个）、**filter 纪律（全场常驻 ≤2 区域）**、零件层必须 trim（否则全屏 overdraw）。
- 工程纪律：所有动画吃统一场景时钟（ticker 累积时间）；tween 挂 Pixi ticker 不自跑 rAF；失焦暂停覆盖 ticker / video / 粒子三类源。
