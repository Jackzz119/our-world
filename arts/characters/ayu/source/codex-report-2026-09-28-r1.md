# 阿屿生产姿势重生成：候选与验收证据

## 1. 模式与归一化 brief

- 模式：design；生产候选重生成，不是概念稿。执行与复核由同一 agent 完成，为自审，未虚构独立第二人。
- 交付：写字、被戳、被摸头、喝水睁眼、喝水闭眼各 3 张，共 15 张 1536×1024 PNG。全部来自内置 image_gen 编辑；未使用 CLI/API-key 生图。

- 闭眼三张全部编辑本批 ayu-sip-open-c3.png；不是分别编辑三张睁眼图。

## 3. 执行结论

**15 张候选及验证证据已完成；本批没有一张满足全部严格生产条件，不建议直接替换上线。**

所有候选均有大量 alpha=0 的真透明像素，尺寸正确；但 alpha=255 像素数全部为 0。锚图本身也没有 alpha=255 像素（最高 254）。这是源文件事实，不能用“锚图也这样”豁免本批的实体不透明要求。

喝水最佳是 c3，但肩线最大偏差 4 px、截断 y=930，仍失败。闭眼最佳是 c1，但眼外精确 RGBA 变化 99.5187%，宽容阈值变化仍 30.9944%，不能作为只改眼睛的眨眼帧。

## 6. 不确定性与可比性限制

- 这些是静态原图检查，没有运行引擎、网格变形或光流过渡；关于闪烁的表述是由像素变化推断的生产风险，不是假称已播放运行时。
- 50% 叠图把两张图分别在同一中灰底按真实 alpha 合成后平均，无位置调整。用于显示轮廓和纹理变化，不是用于修复，也不代表最终场景受光。
- 场景图与精灵的缩放、构图、光照不同，仅比较杯的身份及设计语言，不做场景像素坐标对齐。
- 摸头允许抬头，叠图双线含合法运动；观察到的肩线和衣领变化不属于这一豁免。未追踪每根发丝拓扑，因此没有声称数清所有新增/消失发束。
- 遮挡的躯干线无法由合成单层图恢复；保持 occluded，不捏造隐藏位置。
- 原图 alpha 的测量与用户称“opaque”的用词有差异，已同时报告严格 255 和实际锚值使用的 128 两种口径。
- 工具执行限制：统一命令执行器启动失败；Python 子进程 EACCES，sharp 导入不可用。改用 Node 内置 fs/zlib 的 PNG 解码做测量与证据图，未换用生图 API。PNG 编解码往返 RGBA 一致，且锚图四列 α≥128 数值与 brief 完全相符。附脚本供调用方用其独立工具复核。

## 7. 建议与下一步
