# 对坐人物头像 · 生产交付与自审

## 1. 模式与标准化 brief

- 模式：**design**；生产资产制作，不是概念方向比稿。
- 项目：Our World 第三期「对坐」，真人伴侣／朋友的角色化身；网页与手机使用。
- 交付：两张 512×512 不透明方形聊天／回忆头像，及两张 512×512 RGBA 旧纸圆章日记头像。
- 身份锁：小满的栗棕齐肩碎刘海、金星发夹、琥珀眼、奶油针织开衫、白 T 与细金项链；阿屿的深藏青近黑乱发、细圆框眼镜、炭灰连帽卫衣与抽绳。
- 画风：聊天版为细线稿、柔和赛璐璐与绘画渐变的半写实二次元 CG；日记版为同一人物的暖灰褐墨线、水彩与旧纸质感。
- 无文字、额外徽章、装饰环、外发光；日记只保留纸材质自身的薄边。
- 用户指定四个文件名与本批次目录为交付范围。源图、代码、正式资产目录及设计常驻文档均未改动。

## 3. 执行结论

**推荐交付四张最终文件。身份、成套关系、聊天圆裁和日记透明角均通过本轮同 agent 自审。**

实际生成七次：小满聊天一次，阿屿聊天两次，两张日记各两次。阿屿首稿发顶碰边，已重生成；日记首稿曾显示彩色外围噪点，因此各重生成一次并保留初稿。进一步按 alpha 正常合成，确认透明像素的 RGB 不能当作实际可见黄边；最终稿在深底与纸色底上显示正常。

仍有低等级限制：日记纸面内部原生 alpha 主要为 252–253，并非严格 255。未手动填满 alpha，保留生成通道。实际不透明度约 99%，在本轮目标尺寸检查中没有明显透底。此细节不影响 brief 要求的透明四角，但不应宣称纸面逐像素完全不透明。

## 5. 观察依据与残留缺陷

### avatar-xiaoman.png

直接观察：星夹位于画面右侧，刘海与肩部波浪发接近设定表；正视观众，轻微困倦感、闭口笑；暖肤色与背景分离。针织纹理、白 T、金项链均可见。圆形显示预览中脸、发夹与主要发型保持完整。

低等级限制：36px 下星夹只剩一个金色亮点，五角形与细项链不可能仍有大图精度；身份靠棕发、脸部与奶油衣服的整体关系识别。头顶留白比阿屿少，但未切断主要发型。

### avatar-ayu.png

直接观察：保留阅读原画的狭长眼形、细圆镜、瘦长下颌和深色卫衣布纹。相较首稿，发顶已有完整留白。冷蓝背景与小满的暖色背景构成一组，但肤色、线条、头肩构图和完成度一致。

低等级限制：夜景散景比小满背景更丰富；36px 下眼镜主要读成细暗弧线。面部与背景仍能分离，无妨碍辨认的高对比装饰。脸型一致性为视觉判断，不能作像素级同脸证明。

### journal-avatar-xiaoman.png

直接观察：同样的星夹、眼睛、齐肩发与服装；改成纸上墨线与暖色水彩质感，保留薄纸边，没有额外金属环。512px 深底合成及80px 深／浅底合成无明显锯齿、白色方底或黄色光环。

低等级限制：生成原件的低 alpha 区域携带少量彩色 RGB；正常 alpha 合成后不形成明显彩边。中心半径220px区域 alpha 最小251、最大254、均值252.919。纸面并非全255，不作人工补强。

### journal-avatar-ayu.png

直接观察：保持相同眼镜与深色乱发，灰褐色卫衣与另一张奶油开衫形成层次；两张圆章具有相近直径、纸色、薄边与纹理。80px 下眼镜仍可读。

低等级限制：日记纸面的中心区域 alpha 最小251、最大254、均值252.762。头发仍有一点冷色底调，这是保留人物身份的选择；不是纯单色褐色照片。极低 alpha 像素的 RGB 杂色不等同于正常合成后的可见缺陷。

### 制作与验证方法

1. 仅使用内置 image_gen，逐张传入相关绝对参考路径；没有 CLI／API key 生图备用路径。
2. 工具实际输出1254×1254，原件全部另存于本目录；使用 sharp 0.35.4 Lanczos3 等比重采样到512×512。没有裁出人物、人工修补、改色、重建 alpha 或添画纸边。
3. 读取 PNG 元数据与像素：核对512尺寸、RGB／RGBA、四角及32×32角块、alpha分布；计算SHA-256。
4. 直接查看四张512成品；聊天版另以临时显示遮罩模拟圆裁，检查512与36px。日记另以临时显示合成检查512深底、80px深底和旧纸色底。临时预览仅在内存中显示，未写回成品。
5. 最终日记文件高不透明度黄像素筛查（R>180、G>180、B<100、alpha>128）均为0；这只是辅助定位，最终判断仍以实际像素预览为准。
6. 本机统一 shell 执行器启动失败（helper_unknown_error: setup refresh had errors）；Python 子进程也被环境拒绝（EACCES）。改用可用的 Node REPL 文件读取与现成 sharp 图像库完成保存、重采样和检查。未切换生成方式。
7. 因 shell 不可用，未执行工作树同步脚本；未改动AGENTS.md／CLAUDE.md；相关技能与规范文件可直接读取。

## 6. 不确定性与可比性边界

- 设定表为多视角多表情，阅读原画为低头姿势，最终头像为正视；不能逐像素比较，主要依发型、眼镜／发夹、脸型与服装判断一致性。
- 小狗参考只定义旧格式；其尺寸、内容与渲染媒介不同，不给新旧角色做虚假数值评分。
- 本轮验证的是素材文件及目标尺寸显示，没有修改应用或在真实聊天／日记页面完成接入测试；不宣称已上线。
- 没有进行全网 IP 相似性检索；提示词未指定现有 IP、画师或工作室，画面依用户提供的原创设定生成。不能保证与所有现有角色绝无偶然相似。
- 这是执行端同 agent 自审，尚不是委派方 Monet 的第二次独立复核。

## 7. 推荐与下一步

采用四个无后缀最终文件供委派方复核与后续接入；聊天在运行时做圆形显示，日记直接使用文件原生 alpha，不另抠圆或加环。运行时请遵循标准 alpha 合成，勿将透明像素 RGB 当作实体底色。

本轮完成资产交付；调用者负责将选定文件晋升到正式资产目录、登记最终实现状态，并在实际36px／80px消费者中验收。若后续新增“纸面内部必须每个像素 alpha=255”的硬标准，应重新生成，不能把本批次称为已满足该额外条件。
