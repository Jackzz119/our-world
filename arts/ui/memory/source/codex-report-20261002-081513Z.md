明确视觉要求：

- 四款：蓝色 #b9d3e6 细格、粉色 #efc3cf 小樱花、奶黄 #efe1b4 稀疏圆点、灰绿 #cfe2c4 细斜线；同一套纸质、撕口和低对比印花。
- 正面、平放、均匀柔光；两条长边整体平直，两端短边手撕并有纤维；透明边距。
- 原生 RGBA 透明背景；主体目标约 80% 不透明。用户允许主体未达到 80% 时原样保留，交后续统一 opacity。
- 禁止卷筒、卷曲、透视、折痕、投影、文字、logo、金属与闪粉；禁止抠图、色键、手工修补。

## 3. 执行结论

**四张原生透明 PNG 母版已交付，可进入后续确定性处理；不能宣称已经全部满足运行时验收。**

直接观察：四张是同套横向和纸胶带，短边有不规则撕口，主体有纸纹，印花类型正确；没有明显卷曲、折叠、透视、投影、文字或 logo。粉色与奶黄重生成后印花较首稿清楚，保留了低密度。

实测：四张都是 8 位 RGBA PNG，主体平均不透明度 **99.13%–99.31%**，远高于目标约 80%。它们有真实透明背景，但主体基本不透底。没有用外部背景伪造透明，也没有事后改 alpha。全部六张保存的生成文件（含两张首稿）都与工具原始输出逐字节相同，见 [raw-integrity.json](raw-integrity.json)。

仍未完全满足的点：54px 下樱花细节和纸纤维无法保真；奶黄圆点在奶油纸上仍弱；灰绿较目标 token 更深；透明区有极低 alpha 杂点；可见胶带本身约 7:1，直接拉伸进旧 CSS 容器会改变印花形状。没有把这些问题标成“通过”。

主体测量方法：先求 A≥128 的胶带边界，再向内缩进宽度的 10% 和高度的 20%，对该中央矩形内所有像素求均值。RGB 使用 PNG 未预乘的通道值，包含淡色印花与纸纹，不包含透明边缘；alpha 均值单独计算。此法避免把“空白背景很多”误报为“纸体很透明”。每张的确切 ROI 在下节和 JSON 中。

## 6. 不确定性与可比性边界

- 本次是原始素材生成与自审，没有真实接入网页、手机、WebP 输出、目标文件体积检查或实际设备验收。没有代替调用方的后续定稿。
- 两张使用情境 JPEG 是界面截图，羽毛是另一种透明物件，三者的内容、尺寸和任务不同；没有对它们与新胶带做优劣打分。
- 三底色板使用准确的纯色 #1d2433、#ecdfc2、#ffffff。深色区域模拟暗照片的基准明度，**不是实拍照片**；它能检验透明边与基础合成，不等于在所有照片内容上完成验证。
- 最终小尺寸板左半为 A≥8 bbox 内原像素的等比例缩小，宽度为 54px / 76px；右半额外模拟现有 54×17 / 76×20 CSS 拉伸。四张母版均未裁切、未改尺寸。检查板中等比例高度仅约 7–11px，这是本轮主体比例的实际结果。
- 缩小采用预乘 alpha 的 box-area 面积采样，再以最近邻放大 4 倍；没有锐化或描边。这是可复现的静态检查，不完全等同于各浏览器 / DPR 的插值。4× 展示中的像素块是检查方法，不是原图编码损坏。
- PNG 是 8 位 RGBA；原始文件只有 IHDR、caBX、IDAT、IEND 等块，没有嵌入 ICC 或 sRGB 块。本报告按 sRGB 通道解释数值，没有进行色彩转换，也不声称完成了跨设备色彩管理校验。
- “无投影 / 无卷曲”为直接目视判断；不能从 RGB 均值单独推出。alpha 数值是像素实测，不能用纸的绘画质感代替。
- 单一中央 ROI 均值不会刻画每个印花和撕口的局部差异；精确 ROI、alpha 范围、透明像素计数均已附在 JSON。
