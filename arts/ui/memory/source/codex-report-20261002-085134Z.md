**模式：design。交付状态：四张送审母版、对照板和像素证据已完成；整套未通过全部生产规格。**

按本轮 Monet brief 保留第一轮四种主体及构图，重绘为更粗的暖棕钢笔线，删掉会在小尺寸粘连的细节。主轮廓目标约为主体宽度的 2.5%，次线约一半；指定墨色 #4a3620，淡蓝 #b9d3e6／灰绿 #cfe2c4，少量奶黄可用。主体最长边约占画布 75%，无人物、文字、外部装饰框、投影、厚涂、CG 或扁平矢量图标。

## 3. 执行结论

**四张在 72px 下都明显比第一轮可读，简化方向有效；照片墙和相册最接近目标，日记与放映机仍不达主线比例要求。不能把整组标为生产通过。**

照片墙的双框不再像灰铅笔，相册四边与四个相角不再消失。日记书页轮廓稳了，但它仍比相册轻；放映机虽然减少了旋钮与小脚，卷盘仍依赖较细的线。相册在小尺寸下最稳定，不过原尺寸外框出现了粗记号笔般的均匀圆钝感，牺牲了一部分钢笔的轻重节奏。

放映机第二次生成**没有达到纠错目的**：主线中位从首稿约 13.8px 降到约 12.0px，近黑像素从 1 个变成 3 个。两稿都不应称为合格。保留首稿可供调用方复核，不用选名或报告措辞掩盖失败。

对照板中 22px 文楷标题仍然是阅读入口；在 72px 栏没有观察到插画抢过标题。这里说的是该固定纸面资产检查，不是实装页面或手机硬件验收。

## 4. 测量与概念对应

### 测量口径

- **包围盒**：任一 RGB 通道小于 245 的所有像素；左上角从 0 计数，宽高包含末端像素。近白噪声 253–254 不纳入。
- **主轮廓中位线宽**：在书页／照片框／相册外边／放映机主体外轮廓的人工指定区域中，以编码 RGB 的 `Y = 0.2126R + 0.7152G + 0.0722B < 180` 分出实墨线；逐行或逐列取完整单条墨线，排除交叉、多条线、区域边界截断与笔尖，再以局部斜率校正为垂直线宽。报告是这些取样的中位数，不是假称全图每一笔都同样粗。ROI、样本数、P10／P90、函数全文在 JSON；光栅边缘及取样选择可带来约 1–2px 差异。
- **最暗墨色**：全母版编码 Y 最小的真实像素，保留原 RGB 与坐标。另给出“暗部 1% 均色”，帮助区别单像素极值与常见墨色。暗部样本来自 Y<160 的像素。
- **近黑**：`max(R,G,B)<32` 的诊断计数，与精确黑色 `#000000` 分开。四张精确黑色计数都是 0；这不意味着“从不近黑”已全部通过。
- **72px 等效主线**：原图中位线宽 × 72 ÷ 主体包围盒最长边，只说明缩放后的几何宽度，不等同于浏览器锐度评分。
