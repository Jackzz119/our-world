L · 对比层次

你的反馈：UI 对场景来说颜色对比和层次太低，弹窗快融进场景。同一个夜晚的书房、同样打开聊天卡和一起听，四种玻璃并排（正式组件实拍）。

L1 深玻璃

推荐 · 已实现（默认）

底色单独抽出来、更实更暗（不透明度 +0.17），模糊 18px，霜纹减半，加 1px 暗描边和更深的投影；导航玻璃 0.66；任务窗和内容页背后把房间压暗、虚化。还是 Cinnaglass 的磨砂玻璃，只是不再透出背后的灯。

L2 描金暗夜

备选 · 已实现 ?look=gilded

近乎不透明的墨蓝玻璃，不要霜纹，边上一道金线、顶边最亮。分得最开、最像游戏 UI；比深玻璃更「重」。

L3 暖瓷

只出设计

浅色霜玻璃配深色字，夜景上对比最强，很多恋爱游戏这么做。上线要把每个组件里写死的浅色字一一改掉，所以这一期只在样板里拍了图。

改之前

已替换 ?look=classic

改之前

已替换

托盘透出背后的暖光，层次不清。

参考了什么：Apple 说透明的玻璃下面要垫一层压暗，文字和图标才读得清（Meet Liquid Glass）；NN/g 和几篇玻璃拟态的可读性总结都建议在文字下垫 10–30% 的实色底、8–20px 模糊、1px 约 20% 的亮边（NN/g）；visionOS 的规矩是不要玻璃叠玻璃，里层用实色填充（Create with Swift）；星穹铁道的全屏菜单把场景整个压暗，原神用不透明的奶油色面板（HSR 对比原神的界面）。深玻璃取的是「更实的底 + 硬边 + 深投影 + 内容页压暗」，描金暗夜再往游戏 UI 走一步，暖瓷是浅色那条路。

实装录屏

正式组件在隔离样板里操作录下来的，10 月 1 日全部按深玻璃重录。这台云端容器没有 GPU，场景是软件渲染，录制时暂停了场景，所以阿屿是静止的；真机上他会呼吸、眨眼。

候选 结论
Emil Kowalski 的 skills（13 个，MIT） 动效判断写得最好：何时该动、曲线、时长、按压幅度、弹层从触发点长出、甩动收起阈值、减少动态效果怎么做。适合当动效评审标准；本轮按它的数值做，并按「俏皮的产品可以更有弹性」放宽了回弹。还没装进项目技能库，等你决定。
Motion（motion@13.4） 好用，支持 React 19，但要 29–43 KB（gzip）；位移简写跑在主线程，会和一直在跑的书房场景抢帧。本轮不引入。
Vaul Emil 的底部抽屉库，仓库已标注不再维护。
Base UI Drawer 无样式、带吸附点和非模态的抽屉，以后想换成成熟组件时的首选。
本轮做法 CSS 优先加一个自写的小托盘，没有新增依赖；JS 增加约 9 KB、CSS 约 6 KB（gzip）。
