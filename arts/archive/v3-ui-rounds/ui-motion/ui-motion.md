## 调研：动画库与 Emil 的技能

| 候选                                                                            | 是什么                                                                                                                                                                                                                                                                                                         | 对本项目                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [emilkowalski/skills](https://github.com/emilkowalski/skills)（MIT，13 个技能） | Emil Kowalski（Sonner、Vaul 作者）把动效判断写成的技能：`emil-design-eng`、`animate`（带 RECIPES）、`review-animations`、`improve-animations`、`find-animation-opportunities`、`animation-vocabulary`、`apple-design`、`mobile-native`、`pick-ui-library` 等；安装 `npx skills@latest add emilkowalski/skills` | 适合当动效的**评审标准**：什么该动、曲线、时长、按压 0.95–0.98、不从 `scale(0)` 出现、弹层从触发点长出、退场快于进场、甩动收起阈值 0.11 px/ms、「减少动态效果 = 留淡入、去位移」。它整体偏克制，本项目按其中「俏皮的产品可以更有弹性」放宽了回弹。示例代码还是旧包名 `framer-motion`。**2026-09-30 用户决定装**：10 个适用的原文装进 `ai/jaSkills/`，登记在 [JASKILL](../../../JASKILL.md) |
| [Motion](https://motion.dev)（`motion@13.4`，`motion/react`）                   | React 动画库：弹簧、退场（AnimatePresence）、布局动画、拖拽                                                                                                                                                                                                                                                    | 能用，支持 React 19；但体积 29–43 KB（gzip，拖拽要 domMax），`x`/`y` 简写跑在主线程，会和常驻的 Pixi 场景抢帧；它的 `reducedMotion` 只管位移类属性。**本轮不引入**                                                                                                                                                                                                                         |
| [Vaul](https://github.com/emilkowalski/vaul)                                    | Emil 的底部抽屉                                                                                                                                                                                                                                                                                                | 仓库已标注不再维护，不采用                                                                                                                                                                                                                                                                                                                                                                 |
| [Base UI Drawer](https://base-ui.com/react/components/drawer)（1.8，MIT）       | 无样式抽屉：吸附点、滑动收起、非模态                                                                                                                                                                                                                                                                           | 以后想把自写托盘换成成熟组件时的首选                                                                                                                                                                                                                                                                                                                                                       |
| GSAP 3.15 / anime.js v4 / Lottie、Rive                                          | 时间线动画库 / 轻量动画库 / 设计师动画运行时                                                                                                                                                                                                                                                                   | GSAP 商用免费但不是开源许可；Lottie、Rive 的运行时对一个加载动画太重                                                                                                                                                                                                                                                                                                                       |

**结论**：CSS 优先，再自写一个小托盘（拖动、两档吸附、甩动收起），不新增依赖。浏览器原生能力够用：`@starting-style` 做进场、`transition-behavior: allow-discrete` 做弹窗退场、`linear()` 做弹簧曲线、Web Animations API 做粒子。本轮新增 JS 约 9 KB、CSS 约 6 KB（gzip，与改动前生产构建对比）。

## 动效语言（本轮实装）

| 名称            | 数值                                                                                | 用在哪                         |
| --------------- | ----------------------------------------------------------------------------------- | ------------------------------ |
| `--ease-out`    | `cubic-bezier(0.23, 1, 0.32, 1)`                                                    | 进场、退场、按下               |
| `--ease-in-out` | `cubic-bezier(0.77, 0, 0.175, 1)`                                                   | 屏上移动、失败轻晃             |
| `--ease-drawer` | `cubic-bezier(0.32, 0.72, 0, 1)`                                                    | 托盘升降                       |
| `--ease-pop`    | `linear()` 弹簧，回弹约 10%                                                         | 放开按钮、小红点、气泡、换图标 |
| `--ease-spring` | `linear()` 弹簧，回弹约 3%                                                          | 弹窗、面板、列表逐项、标签滑块 |
| 时长            | 按下 90 · 放开回弹 460 · 悬停 160 · 进场 260 · 退场 150 · 面板 420 · 托盘 460（ms） |                                |
| 幅度            | 按压 0.95（大块 0.97）· 悬停上浮 1px · 进场位移 10px、缩放 0.96                     |                                |

**低动效模式**：设置 → 主题外观 → 动效，三档「跟随系统 / 完整动效 / 低动效」。低动效把上面的位移、缩放、回弹归零、时长缩短，只留淡入淡出；循环（唱片、音柱、热气、光扫）和粒子关掉；房间的视差、微动和蒸汽也一起停（下次进房间生效）。旧棕皮书只跟随系统设置；新的回忆面板跟随这里的三档。实现：[motion.css](../../../../src/themes/cinnaglass/ui/motion.css)、[motion-preference.ts](../../../../src/themes/cinnaglass/ui/motion-preference.ts)。

## F · 交互反馈清单

![F1 反馈语言](img/F1.jpg)

本轮实装的反馈：

- **按钮 / 图标钮 / 行 / 卡**：按下缩 0.95（大块 0.97）、放开回弹，主按钮按下时亮一圈暖金光；鼠标悬停上浮 1px。导航按下回弹，选中时图标轻弹放大、光晕扩开；悬停名称只在鼠标设备出现（触屏轻点不再残留标签）。
- **弹层**：导航的房间 / 工具弹层从按钮方向长出、逐项浮入，收起淡出；B 类任务窗升起、收起下落（Safari / Firefox 没有 `overlay` 属性，收起直接消失）。
- **聊天**：窄卡从左下角升起、收起下沉；消息逐条浮入；❤️ 🌟 快捷表情会迸出小表情；发送时纸飞机飞出去再回来。完整聊天的新消息同样浮入。
- **状态**：未读小红点弹出并放一圈涟漪；纪念日天数第一次出现时逐位滚上来；新来信从上方带点倾斜落下；对方的气泡从脸侧弹出、消失前向上飘走；名牌浮入；日历选中日轻弹。
- **失败**：登录出错时提示轻轻左右摇（不闪红）。
- **入口**：大厅、登录、重置的底图淡入归位、卡片升起、内容逐项出现；等待处是一枚金色小弧线转圈。

## 用户的决定（2026-09-30）

1. 看样页做得好：同步进设计系统（[review/](review/index.html)），并在 Monet / UI Tailor 技能里加一条规则，以后都这样展示 UX；UX 是设计系统参考的重要一环，不能只用 token 表达（[UX 参考](../../uiux/cinnaglass/ux/ux.md)）。
2. 「B · 音乐主页面」标题用的字（站酷小薇）加入项目：`--ui-display`，只用在面板标题。
3. B3 沉浸歌词：要（已实现）。B6 桌面三栏：不要。
4. 海报和歌词先占位。
5. 手机任务窗从下面升起：保留。
6. Emil 的技能：要（已装进 `ai/jaSkills/`，登记在 [JASKILL](../../../JASKILL.md)）。
7. 日记、照片墙的桌面版和手机版也要统一迭代，旧日记先不删（见 [memories](../memories/memories.md)）。
8. 需要美术图时不要自己生成，先用占位，之后在用户机器上装 Codex 生成。

A1 托盘、B5 停靠、D1 + D2 + D5 加载用户没有另外改选，按已实现的推荐方案保留；A2～A4、D3、D4 仍是备选。

## 实现与验证边界

- 验证：`tsc -b`、ESLint、Prettier、`vite build` 通过；[手机回归](../../../features/mobile-ui.md) 12 页 × 8 尺寸 96 组布局、4 类键盘、托盘点击 / 两档 / 工具托盘 Esc、安全区和减少动态效果全部通过。动图由正式组件在隔离样板里操作录制；场景在无 GPU 的容器里软件渲染，录制时暂停了场景 ticker，所以对方人物是静止的。
- 没有验证：真机触摸拖动手感与软键盘、Safari 的弹窗退场、低端设备在场景常驻时的动效帧率。
