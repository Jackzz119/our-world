# 书房第二视角部件生产验收

## 1. 模式与规格

- 模式：design（生产部件编辑；非概念设计）。执行及复核：同一 agent 自审，没有虚构独立复核。
- 三类部件各 3 个候选，每个候选做了 1 次额外生成重试：共 18 张，未超过每文件最多 3 次额外尝试。
- 每张要求 1536×1024 RGBA、物件外 alpha=0，保持原 plate 坐标、尺度和透视；前景手与花杯的严格非透明包围盒各边偏移 ≤12 px。
- 生成只用内置 image_gen.imagegen；编辑输入始终包含被替换原件。没有 API/CLI 生图、抠图、色键、手修、缩放、平移或 alpha 清理。交付 PNG 是生成工具原文件的逐字节复制。
- 杯、袖、衣物保留柔和左暖右冷的画内光；不加发光圈、描边或光环。开衫须自然搭在椅背，不能像被隐形人体穿着。

## 3. 执行结论

**18 张均不放行，生产交付未达标。** 全部 1536×1024，均有真实 alpha=0 像素；但每张存在远离可见主体的 alpha=1 杂点。部分手部另有位移/尺度问题；开衫仍不同程度像穿在人体上。所有图保留 -reject 后缀，未提供伪装成通过的无后缀文件。

外观上最接近的是花杯 c3-r1，严格边界偏移 [0, 0, -2, -1] px，通过 12 px 边界子项，仍因 3 个远处 alpha=1 像素拒收。c1 花杯也通过严格边界子项，但有 1 个远处杂点。不要把“真实透明通道”误读成“物件外完全无杂点”。

## 4. 检测方法与原图基准

坐标用左上为原点、0-based，包围盒为 [左, 上, 右, 下]，右/下包含端点。偏移 = 候选 − 对应原图。

- 严格边界：alpha≥1，即所有非透明像素；这是用户的正式闸门。
- 可见主体辅助边界：alpha≥8，仅用于诊断，**不替换正式阈值**。
- 远处杂点：位于本图 alpha≥8 包围盒外扩 12 px 之外且 alpha≥1 的像素。这个保守判据只统计明确远离主体的像素，不证明框内不存在其他杂点。
- PNG 逐像素解码；自写 PNG filter 解码与独立 pngjs 解码在花杯 c2 上完全一致，再用 pngjs 处理后续。
- 每稿生成 1536×1024 原位叠图：原件与候选分别按原 alpha 合成到 RGB(128,128,128)，两幅结果按 50:50 混合；没有位移或配准。叠图是 QA 证据，不是生产素材。
- 原图及工具预览的黑色/光雾不能直接作为 alpha 判断依据；透明像素 RGB 仍可含亮色。验收以解码 alpha 与灰底合成为准，本报告未把隐藏 RGB 的光雾当作可见光环。

| 原件 | 尺寸 | alpha=0 数量 | 严格 bbox | alpha≥8 bbox | 远处杂点数 |
|---|---|---:|---|---|---:|
| fg-her-hands.png | 1536×1024 | 1436465 | [303, 324, 1447, 1023] | [309, 726, 1211, 1023] | 9 |
| prop-ayu-mug.png | 1536×1024 | 1558679 | [689, 324, 1078, 707] | [944, 584, 1073, 705] | 3 |
| prop-ayu-hoodie.png | 1536×1024 | 1439112 | [450, 215, 1377, 951] | [453, 368, 1052, 653] | 12 |

**基准冲突（直接测量）**：原花杯严格 bbox 的左上是 [689,324]，肉眼主体的 alpha≥8 左上是 [944,584]。原件在 [691,324]、[691,325]、[689,326] 各有 alpha=1 的远处像素。因此，若生成完全干净且保留真实杯子位置，严格左/上偏移约为 +255/+260 px；若保持这组严格边界，则又需要在远处保留非透明像素。手部也有类似冲突。没有擅自放宽闸门，亦未为了通过 bbox 刻意增加杂点。

## 7. 不确定性、可比性与建议

这是同尺寸部件的原位比较；CH-mirror 是不同构图的双面板身份参考，不能与部件坐标直接比较。没有做引擎内多时辰、移动视差或手机取景验证；没有声称可直接上线。边界通过不保证内部手指/杯口/杯柄都完全同位，报告同时保留叠图供复核。低透明度杂点单层肉眼几乎看不到，但用户要求的是严格透明，因此仍拒收。

建议不晋升任何稿件到 source 或 public。后续优先解决定位闸门的基准定义；可考虑明确批准以 alpha≥8 主体 bbox 定位、另设 alpha≥1 远处杂点零容忍，但本轮未采用此变更。只更改阈值也不能消除本批杂点，仍需生成新的干净输出。

本轮在每槽一次重试后停止，未耗尽最多三次的上限：三类共 18 次生成均重复出现 alpha=1 远处像素，且原件的严格定位与无杂点标准存在可测冲突。继续重复同类提示不能合理证明将得到满足全部规则的结果；因此交付失败证据，不把外观较好的稿件冒充生产件。
