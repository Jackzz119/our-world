# 书房晴夜底图制作与验收

## 1. 模式与规范化任务

- 模式：design；生产底图的局部天气编辑，不是概念改版。
- 为开灯、关灯原图分别去除两块窗玻璃上的雨丝、水珠、水流与折射痕迹，保留同一夜景城市和河面灯光倒影。
- 尺寸固定为原图 1536 × 1024。窗框、遮挡窗面的植物、家具、灯光、桌面、唱片机、书、拍立得与墙面均应保持原状。禁止新增光圈、描边。
- 使用内置 image_gen，分别传入对应原图绝对路径；未使用 CLI/API-key 生成路径。所有生产图均直接来自生成工具，无后抠、手修、缩放或拼接。
- 自审由本执行 agent 完成，不声称存在第二位审核者。

## 5. 检查方法与详细发现

使用 PNG 解码后的原始 8 位 RGB 数值比较，没有自动对齐、色彩补偿或缩放。平均绝对误差（MAE）按三个通道的绝对差取平均，单位为 0–255 色阶。它测量像素变化，不等同于几何位移。

| 完全位于非窗玻璃内的检测区域 | 开灯返工 MAE | 关灯返工 MAE |
| --- | ---: | ---: |
| y≥650 的桌面及下方 | 2.54 | 2.73 |
| 椅背实体区域 | 2.20 | 2.17 |
| 灯罩内部 | 3.86 | 3.16 |
| 窗框实体窄条 | 3.65 | 1.95 |
| 唱片机盖内部 | 2.99 | 2.85 |
| 左墙区域 | 3.18 | 3.36 |
| 右书架区域 | 2.24 | 3.48 |

所有 ROI 坐标、最大通道差、不同像素数量、输入/输出 SHA-256 及初稿数据均保存于 pixel-qa.json。

五条局部边缘扫描使用指定窄条内“相邻像素 RGB 差的横向或纵向均值最大值”定位边缘梯度峰：
- 开灯：椅子左边、桌面前沿、唱片机底座右边、拍立得下边峰值位置相同；窗框左边相差 +1 px。
- 关灯：窗框左边、椅子左边、桌面前沿、唱片机底座右边峰值位置相同；拍立得下边相差 -1 px。
- 直接叠图未见大幅家具位移或整体缩放；局部对照显示细微边缘锐度与色值变化。梯度峰差可能来自重绘或抗锯齿变化，不能机械等同为整个物体位移 1 px。

局部对照图保持原始像素、不缩放：左半为原图，右半为返工稿。
- qa-on-source-left-revision-right.png：原图区域 x=950、y=0、w=70、h=420。
- qa-off-source-left-revision-right.png：原图区域 x=1060、y=780、w=180、h=110。

## 6. 不确定性与可比性限制

- 每个候选仅与其对应灯态源图作直接验收，尺寸、取景一致，可比较。
- 仅对选定边缘进行数值扫描，没有穷举每片叶子与所有物体边缘；不能以抽样通过代替“所有边缘”通过。
- 在全图与所查局部未见残留窗面雨痕，但未做逐滴人工穷举。唱片机盖上原有纹理不是窗玻璃清理目标。
- 原图被雨水遮挡的城市细节由模型补全；无法证明补全与被遮挡的真实底层像素一致。
- 未接入 PixiJS、未测试运行时交叉淡化或手机裁切；本报告不宣称运行时验收通过。
- 内置工具参数没有本任务可用的硬遮罩/锁像素参数，文字约束与返工未达到完全像素保持。没有用外部 API 或手工合成绕过生产约束。
