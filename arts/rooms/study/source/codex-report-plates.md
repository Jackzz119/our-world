# 书房生产素材 · Codex 交付报告

## 1. 模式与规范化任务

- 模式：**design**。任务是生产资产制作，不是方案比稿。
- 视角：小满为摄像机；前景奶油色针织袖口和双手握杯；对面阿屿穿炭灰连帽衫、戴细圆框眼镜，双手持平装书阅读。
- 锁定：参考中的高完成度二次元 CG、左暖灯与右侧冷窗光、窗边木桌、左台灯、右开盖唱片机、水平桌远沿、窗后雨夜城市。
- 交付：一张全景主图；从主图移除活动物件的夜晚开灯底板；夜晚关灯、蓝调开/关灯、金色时段开灯四张变体。
- 全部位图通过内置 `image_gen` 生成/编辑。没有 API-key/CLI 生图，没有抠图、手修、颜色滤镜、缩放、拼贴或配准改写。落盘仅逐字节复制工具输出。
- 已读取当前 `ai/PROJECT.md`、`ai/TODO.md`、`ai/JASKILL.md`、设计系统及 scene / character / props 规范。本轮是既有委派的执行端，未再次委派给其他 agent。

## 3. 执行结论

**六张指定 PNG 均已交付，全部为原生 1536 × 1024、8-bit RGB、不透明。四张光照变体相对统一夜晚开灯底板，抽检的固定边缘最佳位移均为每轴 0–1 像素；可以交给 Monet 进行原位合成复测。**

**整批不宣称严格验收全通过：**

1. 主图头顶留白约 **11.8%**，多于 brief 的约 8%。
2. 主图转空房时，木椅右柱仍向左偏约 **28 px**；返工显著减小了初稿的偏移，但未归零。这一偏差发生在 **master → plate-night-on**，不是五张空房光照底板彼此之间。
3. 左侧花瓶与花束贴边，花瓶左沿约 x=30，未满足所有物件距边缘 4% 的严格解释；人物头脸、杯子、台灯主体、唱片机主体均未被裁切。袖口从底边进入是 brief 所需。
4. 内置工具没有可设置的尺寸参数；已在提示词要求最大横图，实际返回 1536 × 1024。不能据此证明这是后端支持的绝对最大尺寸，也没有把它插值放大冒充高分辨率。

本轮为同一 agent 的生成后自审；未声称完成 Monet 的独立复核，未接入 PixiJS、未实测运行时帧率或交叉淡化。

### 5.2 固定几何抽检方法

直接解码 PNG 原始 RGB；计算亮度 `0.2126R + 0.7152G + 0.0722B` 的水平/垂直中心差分梯度。对 11 个 ROI 在 **±6 px 整数平移**范围比较归一化梯度向量相关性，像素采样步长为 2；记录最佳 dx、dy。没有将图片平移、拉伸、校正或重新保存。

ROI 覆盖：上方窗中竖框、左窗框、灯罩顶边/右边、椅背左/右上角、桌远沿右段、桌前沿、唱片机盖右上角、木箱前角、拍立得。完整 ROI 坐标、每项 dx/dy 与相关分数见 measurements.json。

| 与 plate-night-on 比较 | 最大每轴位移 | 边缘相关分数范围 | 判断 |
| --- | --- | --- | --- |
| plate-night-off | 1 px | 0.741–0.927 | 关键边缘稳定；关灯后的强度变化降低相关性。 |
| plate-twilight-on | 1 px | 0.397–0.955 | 关键物件稳定；窗框附近同时去雨、换天空，分数较低。 |
| plate-twilight-off | 1 px | 0.343–0.920 | 同上；多处为 (-1,-1) 或 (0,-1) 的细小偏差。 |
| plate-golden-on | 1 px | 0.240–0.925 | 家具轮廓稳定；窗区及逆光椅柱因受光反转，低分区不能作强证据。 |

这些是**局部刚性平移的抽检结果**，不是全幅形变检测，也不是“像素完全不变”的证明。已结合逐图轮廓观察判断，没有发现需要从基准重做的明显光照变体几何漂移。真正运行时淡化是否可见细纹游动，仍要在引擎里检查。

master 与底板比较：窗框、灯罩、唱片机、拍立得抽检位移主要为 0–1 px；桌前沿中央 ROI 在 master 中被手和袖子遮挡，相关分数仅 0.061，**该项无比较意义，不能用其 (5,-2) 结果声称桌子漂移**。椅背偏差用露出的右柱目视判断单独报告。

采样位置固定：灯罩内部矩形 (145,330,45,50)，桌面灯光池矩形 (370,730,50,50)，格式为 (x,y,width,height)。均值是 sRGB 编码数值上的亮度代理，**不是线性物理照度**。

| night-on | 220.1 | (232.5,161.9,97.4) |
| night-off | 28.2 | (58.2,86.7,138.5) |

## 6. 不确定性与可比性限制

- 参考 A1/黄金/蓝调是 16:9 左右的概念图，本批输出是 3:2；人物、动作和唱片机开盖状态也不同。它们是风格与光感依据，不是对齐候选。
- 五张空房底板尺寸、视点和物件内容一致，适合直接原位比较；主图多人物/手/杯/唱片/唱臂，遮挡区域与空房不能直接以整幅像素差评判。
- 生成的“干玻璃”移除了明显雨滴；唱片机盖上仍有材质斑点和反光细节，不能从静帧确定是灰尘、玻璃反射还是雨纹语义残留。
- 城市窗灯“陆续亮起”这里只表现为静态灯点状态，未生成时间序列。
- 未画真实透明活动部件；主图中的人物、唱片、拉链是效果参照，不能直接裁切当生产透明件。
- 这不是最终运行时雨层遮罩、人物 rig 或唱片椭圆标定。窗口顶部超出画布，玻璃矩形也有植物/椅背遮挡。
- 工作区终端无法启动，错误原文：`Failed to create unified exec process: helper_unknown_error: setup refresh had errors`。因此保底脚本 dry-run 未能执行；改用文件工具读取规范、保存并验证产物，没有修改协议、技能、业务代码或项目状态文档。

## 7. 建议与下一步

1. **以 plate-night-on.png 为五张空房底板的统一几何基准**，不要使用 initial 草稿接入。四张光照变体未见明显宏观几何跳变。
2. Monet 先复测右椅柱和头顶留白这两项残差，再决定是否接受此版主图/底板关系。若严格“叠回主图等于原图”是硬门槛，当前批次仍不能标绿。
3. 用本报告坐标作为测量起点，重新精测盘面透视、窗格遮罩、人物锚点；以后续原生透明人物/杯子/唱片/唱臂/拉链与此固定底板坐标系对接。
4. 活动部件继续依用户要求直接生成真正 alpha、平光固有色；静物底板保持本批画内光照。不要从本批整幅图手工抠件。
5. 在实际 PixiJS 原位叠加与时辰淡化时，重点查看椅柱、唱片机盖、桌前沿、拍立得，以及雨纹/桌面细纹是否游动。
