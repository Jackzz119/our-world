Style/medium: clearly hand-painted 2D storybook illustration with soft pastel gouache texture and simplified shapes; warm quiet light; not a 3D render.
Composition/framing: high three-quarter isometric cutaway, stable orthographic-like geometry, whole home readable at a glance. Preserve calm negative space along the left edge for a vertical translucent navigation shell and on the right for a floating bright-white memory panel; show only abstract blank glass UI shapes, no readable text.
Lighting/mood: golden hour, warm window light, gentle deep-blue shadows.
Constraints: exactly two mascots; both readable at thumbnail size; hotspots visible but quiet; background scene remains the star; UI content paper is the brightest element; no logos, no trademarked character design, no watermark, no readable text.
Avoid: photorealism, shiny 3D CGI, free-camera game HUD, busy particles, excessive decor, neon, hard black outlines, text gibberish.
