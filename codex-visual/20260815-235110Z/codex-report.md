# 可交互物件提示 v2：金色贴形描边光 + 星光

## 1. Mode and normalized brief

- **Mode：Design**
- 目标：为书房五个可点物件建立非 UI 框式的环境内提示语言。间歇提示态只让日记本与许愿罐在当前瞬间发光；hover 态只让许愿罐进入更强确认反馈；另提供一张 4:3 描边规格板。
- 视觉语法：沿真实物件 alpha 轮廓生成“内侧亮金线 → 中层暖光 → 外层柔晕”，叠加大于旧版的四角星芒；颜色限制在场景台灯/许愿罐同族的 `#FFE6B5`–`#FFC978`。
- 不变量：水彩纸纹、黄昏蓝紫环境、暖木家具、物件位置与整体视角；禁止矩形框、白环、全热点同时闪烁、鼠标图标与额外 UI。
- 执行方式：使用 bundled `imagegen` skill 与内置 `image_gen`，每个资产独立生成；未使用 CLI/API-key fallback。输出仅作美术 mockup 与实现规格，不覆盖参考源图。

## 3. Executive verdict

采用“贴形描边为主、星芒为峰值”的组合方案。`hint-state.png` 已达到优雅但可见的提示强度，`hover-state.png` 与之形成清楚的二级反馈；二者在完整场景里无需文字或 UI 框即可定位目标。程序实现时必须基于每件物体的独立 alpha mask/SDF 生成轮廓，不能用热点矩形的 `box-shadow` 代替。

## 4. Concept matrix

| 维度 | 间歇提示态 | Hover 确认态 | 判定 |
|---|---|---|---|
| 主信号 | 2–4px 贴形亮边，外晕克制 | 3–5px 更实亮边，外晕约 1.7–2.0 倍 | 两态差异清楚 |
| 星芒 | 每物件 2–3 颗，主星 20–32px | 4–6 颗，主星 36–48px | hover 抓眼更强 |
| 物件本体 | 不改或仅 +2% 亮度 | 亮度 +8–12%，饱和度 +4–8% | 保留水彩纹理 |
| 同时亮起数 | 本 mockup 为 2 件；运行时最多 2 件 | 仅当前 hover 物件 | 避免找物游戏感 |
| 非目标物件 | 完全安静 | 完全安静 | 通过 |
| 轮廓形态 | 沿书页、书脊、瓶肩、瓶底、把手 | 同一 mask，更强参数 | 禁止矩形框 |

## 5. Detailed findings and implementation spec

### 5.1 描边分层参数

以下数值以 1586×992 的场景基准为准；画面等比缩放时所有像素值乘以场景缩放系数。推荐先生成物件 alpha mask，再用 signed-distance-field 或 `dilate(mask) - erode(mask)` 得到连续轮廓；每层共用同一 mask，避免三层彼此漂移。

| 层 | Hint 参数 | Hover 参数 | 合成建议 |
|---|---|---|---|
| 内侧亮金线 | 2–3px；`#FFECC7`；alpha 0.82–0.92 | 3–5px；`#FFF0CC`；alpha 0.95–1.00 | `screen`；边线允许约 40% 压进物件内部，保留“边缘被点亮”感 |
| 中层暖光 | 6–9px；`#FFD88F`；alpha 0.38–0.52 | 10–16px；`#FFD078`；alpha 0.58–0.74 | `add`/`screen`；高斯模糊半径取层宽的 0.55–0.7 |
| 外层柔晕 | 14–22px；`#FFC978`；alpha 0.14–0.24 | 28–42px；`#FFC56E`；alpha 0.26–0.40 | `screen`；水彩式非均匀羽化，可叠 3–5% 低频噪声打散数字光圈感 |

约束：总发光不得把浅色日记页压成纯白；峰值时页面高光建议不超过 sRGB `RGB(250, 229, 190)` 的大面积覆盖。许愿罐内部原有星形灯保留，轮廓只负责界定瓶身可点范围。

### 5.2 Hint 呼吸与轮流节奏

- 一次提示脉冲总长 **2.2s**：淡入 420ms（`ease-out-sine`）→ 峰值停留 420ms → 缓慢淡出 1.08s（`ease-in-out-sine`）→ 280ms 余辉。
- 轮廓 alpha：`0 → 1.0 → 0.88 → 0`；外晕 scale：`0.92 → 1.05 → 1.00`，不要持续循环缩放。
- 每组提示后的静默间隔随机 **6.5–9.5s**；每次选择 1–2 件，运行时硬上限 2 件。五件物体在 **30s** 内至少各出现一次，连续两组不得完全相同。
- 两件同亮时错开 **180–320ms** 起动，避免机械同步；本次 `hint-state.png` 是两件同时处于高峰的展示帧。
- 鼠标进入任一热点时立刻取消该物件未完成的 hint，并在 80–120ms 内过渡到 hover 参数，避免先暗后亮的断层。
- `prefers-reduced-motion`：取消缩放、漂移和粒子位移，仅做 450ms 静态淡入/淡出；提示间隔放宽到 12–18s。

### 5.3 Hover 强化参数

- 进入：**160ms**；退出：**260ms**。轮廓不呼吸，保持稳定确认，仅允许外晕以 1.4s、±6% alpha 做极轻微呼吸。
- 物件本体：brightness `1.08–1.12`，saturation `1.04–1.08`；不要整体放大，避免点击热区与视觉位置错位。
- 外晕峰值半径为 hint 的 **1.7–2.0 倍**；内线 alpha 至少比 hint 高 0.10。
- hover 星爆首轮持续 **620–760ms**，之后保留 1–2 颗小星以 1.1–1.5s 随机闪烁；移出时剩余星芒在 180–260ms 收尾。
- 可选罐顶大星：36–48px，中心位于瓶盖上方 12–24px，不与瓶口亮边完全粘连。

### 5.4 星光与描边配合规则

- 星芒采用四角主峰，中心 `#FFF6DC`，中段 `#FFE2A3`，外晕 `#FFC978`；主峰横纵比例可在 0.75–1.25 间随机，避免复制章感。
- Hint：每件 2–3 颗；主星 24–32px，辅星 14–22px。Hover：4–6 颗；主星 36–48px，辅星 18–30px。
- 星心距轮廓外缘 **6–18px**；至少 60% 星芒落在物件上半部或视线进入方向。不要把星心全部压在线上，否则会把连续轮廓切碎成火花链。
- 同一时刻最高亮星不超过 2 颗；其余星 alpha 0.45–0.75。相邻星峰值错开 90–160ms。
- 星芒不得跨到相邻热点的 silhouette 内；许愿罐与信件架之间需保留可见暗缝，日记本星芒不得落到笔筒上。
- 小于 960px 宽时，将星芒尺寸下限锁在 14 CSS px，而不是继续等比缩小；小窗 640×400 时建议只保留 1 主星 + 1 辅星。

### 5.5 可见质量结论

- `hint-state.png` 中书页前缘、书角、罐肩与罐底的金线均连续，直接证明目标是物件轮廓而非 UI 矩形。
- `hover-state.png` 中许愿罐比 hint 有更宽外晕、更密集星芒和更亮本体，且日记本回到普通状态，确认态层级成立。
- `glow-detail.png` 的上下排在相同对象与相近背景下比较，hover 的亮线、柔晕与星芒峰值均显著增强，可作为 shader/filter 调参视觉靶标。

## 6. Uncertainty and comparability limits

- 三张成品是基于参考图重新生成的 mockup，不是对同一底图做像素级叠层；家具细节、窗景和物件比例存在轻微生成漂移。因此可比较“效果语言与相对强度”，不可用它们做逐像素状态切换回归。
- `hint-state.png` 与 `hover-state.png` 的背景构图相近但不是完全同帧；正式实现验收应在同一原始场景截图上开关 filter 后再做 A/B。
- `glow-detail.png` 的 `HINT` / `HOVER` 仅为规格板说明，不属于产品 UI，也不应出现在运行时。
- 透明度参数是从视觉目标反推的首版实现值；PixiJS 的 blend mode、色彩空间和设备 DPR 会改变峰值观感，最终需在 1586×992、960px 宽和 640×400 三档实机截图上微调。

## 7. Recommendation and next actions

1. 为五件热点分别制作紧贴物件的 alpha mask；把 mask 作为唯一形状真源，热点矩形只负责 hit-test。
2. 先按本报告三层参数实现 hint/hover 两套 preset，再在同一 twilight 截图上做开关 A/B；验收重点是非目标物件是否被光晕污染。
3. 按 2.2s 提示脉冲与 6.5–9.5s 静默间隔接入轮换调度；同时提示上限锁为 2。
4. 在 960px 与 640×400 两档检查星芒最小尺寸、日记页是否过曝、许愿罐与信件架是否仍有暗缝；低亮度屏另验一次。
